BUILD IT ON YOUR MAC

Mac版は手元でビルドできます

Mac環境でソースから作る方法を用意しました。 一度コマンドを実行すれば、Apple Silicon／Intel両対応の Universal版ZIPが生成されます。

⌘ Macビルド用ソースをダウンロード ZIP・CMakeで依存ライブラリを自動取得
1

開発ツール
xcode-select --install

2

CMake
brew install cmake

3

Universal版を作成
sh scripts/build-macos.sh

Mac版の詳しいビルド手順を見る

ソースZIPを展開したら「ターミナル」を開き、次を上から順番に実行します。 

xcode-select --install
brew install cmake
cd ~/Downloads/keyboardmania-midi-bridge-source
sh scripts/build-macos.sh

成功すると、ソースフォルダー内の dist/keyboardmania-midi-bridge-macos-universal.zip に完成品が作られます。初回起動方法やエラー対処は 詳しいMacビルド説明書を確認してください。

Homebrewを使わない場合は、CMake公式サイトからmacOS版を インストールしても構いません。ビルド中はインターネット接続が必要です。

03

IF SOMETHING IS WRONG

困ったとき

コントローラーを探す表示から進まない

USBを一度抜き、数秒待ってから挿し直します。 USBハブではなく、パソコン本体へ直接つなぐのも試してください。

MIDIポートがないと言われる

loopMIDIを起動し、Keyboardmaniaポートが 作られていることを確認してから、Bridgeを起動し直します。

Readyなのに音が鳴らない

DAWのMIDI入力、ソフト音源、録音待機または入力モニターを確認します。 詳しい確認方法は同梱のREADMEにまとめています。
