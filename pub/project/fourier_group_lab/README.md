## 実験

1. **DFT** — 数式の波形 → 4〜64個の等間隔標本 → 両側複素スペクトル → 逆変換。標本数、右への巡回シフト、反転 `x[n] → x[-n mod N]`、シャッフル、2点の交換、値の直接編集に対応します。低域だけを残す再構成、振幅・位相の数値、全係数表、RMS誤差、Parsevalの等式を表示します。
2. **有限アーベル群** — 同じ4つの実数を `Z/4Z` と `Z/2Z × Z/2Z` に置いて比較します。群の足し算に沿った移動、4つの指標、複素係数、逆変換を表示します。スペクトルは指標を横軸にした4本の棒と位相の針で表示し、2×2の群では双対群上の2×2周波数マップも併記します。大きさ `|F|` / エネルギー `|F|²` を切り替え、棒・マップ・選択欄から成分の意味、係数、位相、エネルギーの割合を確認できます。縦軸と色の範囲は自動調整です。ゼロ係数の位相は未定義として扱います。一般の有限アーベル群を自由指定する機能ではなく、構造の異なる2例を比較する入門です。
3. **非可換な有限群** — 正三角形の対称性 `S3 ≅ D3`。回転と鏡映の順序、操作6個上の関数、自明・符号・標準表現による変換（1×1、1×1、2×2）、成分のオン・オフと逆変換、掛け算表を扱います。一般の非可換群や連続群の変換は対象外です。
4. **数列を持ち込む** — 1〜64個の実数・複素数を貼り付け、同じ要素数の群を左右で比較します。巡回群、要素数の因数分解から得られる巡回群の直積、6要素のS3、8要素のD4を選択できます。各成分のエネルギー、複素係数・行列、全係数表、入力順と群の要素の対応、逆変換、RMS誤差を表示します。ガイド、例、01の現在の標本の取り込み、明示的ゼロ埋め、2点の交換、シャッフル、復元、群に沿った移動もあります。

各実験に段階的なガイドと「やってみる」操作があり、自由実験にも切り替えられます。

## 自分の数列を比較する

「04 数列を持ち込む」で、例えば `1, 0.5, -1, 0, 2, -0.5, 0.3, -0.8` を貼り付けて適用します。8個なら `Z/8Z`、`Z/4Z × Z/2Z`、`(Z/2Z)^3`、`D4` が候補です。素数個なら巡回群が候補になります。

- カンマ・空白・改行が区切りです。`1+2i`、`-i`、`2e-3` に対応します。複素数の内部には空白を入れません。空のCSV項目、非有限値、絶対値100万超、65個以上はエラーにし、直前の計算結果を保持します。
- 群は入力数と要素数が一致するものだけです。余分な値を切り捨てたり、暗黙に0を足したりしません。「末尾に0を追加して適用」でだけ個数を増やせます。
- 同じ要素数の群へ切り替えても、数列の並びは固定です。直積の添字は右端から先に増加します。同型な群も候補に含まれます。例えば `Z/6Z ≅ Z/3Z × Z/2Z` ですが、画面の列挙順は同型写像の対応順とは限りません。スペクトルの違いをすべて「非同型だから」と解釈しないでください。
- 巡回群の直積は、要素数Nの乗法的分割を列挙して作ります。全有限群の分類・任意の掛け算表の読み込みは行いません。非可換群はS3とD4に限ります。
- D4は正方形の8要素の対称群。順は `e,r,r^2,r^3,s,rs,r^2s,r^3s`、`r`は90度回転です。1次元表現4つ（r,sをそれぞれ±1に写す）と、平面の動きに対応する2次元表現1つを使います。
- 棒は `dρ ||F[ρ]||²_F`。左右共通の縦軸で、各成分が持つエネルギーを比較します。全棒の合計は入力の `mean(|x|²)`。行列全体に1つの位相は付けず、全係数表に要素ごとの位相を表示します。成分番号が同じでも、左右で同じ表現とは限りません。
- 片側の群に沿った移動 `T_h f(g)=f(h^-1 g)` は共通入力を並べ替えます。その側の各ブロックのエネルギーは保存され、もう片側の成分分布は変わる場合があります。
- 音は入力順の「実部」または「虚部」を明示的に選んで再生します。下の音声機能と連携し、逆変換音はA/Bを選べます。全成分で復元するため、入力音と再構成音は数値誤差の範囲で同じです。1要素の定数列はDC除去で無音になります。

## 数学上の規約

- 全変換で順変換を群の位数で割ります。DFTは `F[k]=(1/N) Σn x[n] exp(-2πikn/N)`。
- 逆DFTは `x[n]=Σk F[k] exp(2πikn/N)`。入力は実数。正負の周波数をペアで残します。偶数NのNyquist成分は1つとして扱います。
- 窓関数やクリッピングを解析データに適用しません。平均除去は明示的に選んだ場合だけです。平均除去時はN個の標本の平均を、標本と参考波形の両方から引きます。
- 有限アーベル群は `F[χ]=(1/|G|)Σg f(g) conjugate(χ(g))`。
- S3は順に `e,r,r²,s,rs,r²s`。`g=r^a s^b` とし、`(a,b)(c,d)=(a+(-1)^b c mod 3,b+d mod 2)`。
- `ρ(r)` は120度の平面回転、`ρ(s)=diag(1,-1)`。図では第1座標を上向き、第2座標を右向きに取ります。
- 非可換変換は `F[ρ]=(1/|G|)Σg f(g)ρ(g)*`。逆変換は `f(g)=Σρ dρ tr(F[ρ]ρ(g))`。
- エネルギーは `(1/|G|)Σg |f(g)|² = Σρ dρ ||F[ρ]||²_F`。S3標準表現の重みは2です。
- 全成分による往復誤差と、成分を減らした再構成の誤差を別々に表示します。浮動小数点誤差のRMSが `1e-10` 未満なら `≈ 0` と表示します。

## 数式

元ツールの `ph`、数式による波形、行ごとの変数定義、コメント、主な数学・ビット演算関数という使い方を引き継いでいます。構文解析器は、このプロジェクト用の依存なしの実装です。JavaScriptの `eval` / `Function` は使いません。

- `ph` は `[0,1)` の周期内位置。標本は `ph=n/N`。
- `t=ph/基準周波数`、`sr=N×基準周波数`。元ツールの2048点テーブルと仮想サンプルレートの定義を、そのまま引き継いだものではありません。
- `t`・`sr` を使う式では、基準周波数を変えると標本も再生成します。通常の `ph` のみの式では、基準周波数は演奏の音高を変え、手編集・並べ替えした標本は保持します。
- `sin,cos,tan,asin,acos,atan,exp,log,sqrt,abs,sign,floor,ceil,round,min,max,tanh,pow,step`。
- `i32,u32,band,bor,bxor,bnot,shl,shr,ushr,rol,ror,and,or,not`。
- 四則演算、`%`、べき乗 `^`、比較・連鎖比較、論理 `and/or/not`、条件 `条件 ? 値 : 値`。
- 掛け算は `*` で明示します。配列、複素数リテラル、暗黙の掛け算、関数定義、任意のJavaScriptは扱いません。
- 変数代入は1行1つ・再代入なし。最後の行に出力式を1つ書きます。`#` または `//` 以降はコメント。
- 式は6000文字・60行まで、1式300トークンまで。出力が非有限または絶対値100万を超える場合はエラーを表示し、最後の成功結果を保持します。

## 音

- 元の数式を512点で近似した波形、現在の標本、再構成した標本を比較できます。2秒の試聴、最大8音の鍵盤演奏、44.1kHz/16bit/mono WAV保存に対応します。
- 等間隔の実数標本から三角多項式の係数を作って1周期として再生します。音声側だけでDC除去、出力のNyquist周波数以上の倍音除去、ピーク上限に基づく減衰、音の開始・終了時の短いエンベロープを適用します。波形の分析値は変えません。
- 画面上の音量はマスター値です。8音同時演奏の余裕を持たせるため、各音はその1/4のゲインを上限とします。WAVも同じゲインです。WAVの周期補間は8192点の内部テーブルを使用します。
- 定数のみの入力は、DC除去によって無音になります。音高が10〜12000Hzを外れる鍵盤はエラー表示します。
- 群から音への写像は時間順序を追加する操作です。Z4は0,1,2,3、V4は(0,0),(0,1),(1,0),(1,1)、S3はe,r,r²,s,rs,r²sの順に読みます。群に固有の「唯一の音」ではありません。
- 音律は12平均律・純正長音階・五音音階および独自入力。比とセントの行、最後の行が周期、1/1を自動追加します。周期比は1より大きく16以下です。
- A=0段、Q=+5段、1=+10段、Z=−5段。入力欄の編集・フォーカス離脱・タブを隠す操作で音を停止します。Escと停止ボタンも使えます。

元ツールの独立したPartialsリスト、仮想サンプルレートによるsample-and-hold、URLへの状態保存は、この学習用UIには移植していません。倍音の重ね合わせは数式で記述できます。
