「有限アーベル群」は、組み合わせる順番を変えても結果が同じ有限群。基本成分はすべて1次元なので、各係数はひとつの複素数で表せます。

定義をもう一歩

入力は f : G → ℂ。ここでは操作しやすい実数の入力を使います。指標 χ は χ(g+h) = χ(g)χ(h) を満たす複素数の模様です。

F[χ] = (1/|G|) Σg f(g) conjugate(χ(g))

f(g) = Σχ F[χ]χ(g)

4点の輪：χk(j) = exp(2πikj/4)。2×2の群：χ(a,b)(x,y) = (−1)^(ax+by)。同じ4点でも、この2つの群は同型ではありません。一般の有限アーベル群は巡回群の直積で表せます。この実験では最小限の例で違いを観察します。

FOURIER BLOCKS / 変換の結果

数が2つ、行列が1つ。

「表現」は操作を行列で表すルール。「既約表現」はそれを分解して得る基本単位です。チェックを外すと、その成分を抜いて逆変換します。

2×2行列の行・列は平面のx・y方向を基準にしています。座標の取り方で行列の見た目は変わりますが、逆変換で戻る値は同じです。

行列の定義・逆変換・掛け算表

入力：f : G → ℂ。変換の添字は、群の要素ではなく「既約表現 ρ」です。

F[ρ] = (1/|G|) Σg f(g)ρ(g)*　（* は共役転置）

f(g) = Σρ dρ tr(F[ρ]ρ(g))　（dρ は行列のサイズ）

この実験の3つの表現は、常に1を返すもの、回転で+1・鏡映で−1を返すもの、三角形の平面上の動きを表す2×2行列です。ρ(r) は120°回転行列、ρ(s) = diag(1,−1)。図では第1座標を上向き、第2座標を右向きに描きます。

非可換でも有限群なら、この定義で有限個の行列へ変換し、逆変換できます。このページは非可換フーリエ変換の有限群での入門例です。

数列を貼り付けると、値の個数に合う群を選べます。値の集合・並び順を保ったまま、群の構造によって分解がどう変わるか比べましょう。

カンマ・空白・改行で区切ります。例：1, -0.5, 2e-3, 1+2i, -i。複素数の中には空白を入れません。

数学の規約と正方形の表現

入力 f : G → ℂ。F[ρ] = (1/|G|) Σg f(g)ρ(g)*、逆変換は f(g) = Σρ dρ tr(F[ρ]ρ(g))。* は共役転置です。入力が複素数のときも、実部・虚部を保って計算します。

D₄はここでは正方形の8要素の対称群を指します。rは90°回転、sは鏡映で、r⁴=s²=e、sr=r⁻¹s。既約表現は1×1が4つ、2×2が1つで、1²+1²+1²+1²+2²=8。1次元表現ではrとsをそれぞれ±1に写し、2次元表現では平面上の回転・鏡映の行列を使います。

群の移動は Tₕf(g)=f(h⁻¹g)。全体のエネルギーは保たれ、各ブロックのエネルギーも保たれます。左右は同じ数列を共有するため、片側の群に沿って移動するともう片側にもその並びを反映します。もう片側では各成分の分布が変わる場合があります。
