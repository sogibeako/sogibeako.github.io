# τの庭 / Modular Garden

τの庭は、モジュラー形式の入口にある上半平面、格子、複素トーラス、q展開の関係を動かしながら観察するためのWebアプリです。

点 τ をスライダーまたは上半平面上のドラッグで動かすと、格子 Λ = Z + Zτ が変形し、q = exp(2πiτ) が単位円内を動き、E4, E6, Δ, j の近似値が変化します。

## 開き方

ローカルサーバーが `pub` を `http://127.0.0.1:8030/` で配信している場合:

```text
http://127.0.0.1:8030/project/modular_garden/index.html
```

## MVP機能

- 上半平面ビューと基本領域表示
- 基本領域内の代表点 τ_F の半透明表示
- τ のスライダー操作とドラッグ操作
- 格子 Λ = Z + Zτ の描画
- 基本平行四辺形によるトーラス表示
- q = exp(2πiτ) の単位円内表示
- 基本領域、E4、E6、Δ、j を切り替えて見るモジュラー模様
- T, T^-1, S 変換
- 基本領域への簡易還元
- E4, E6, Δ, j のq展開近似
- モジュラー形式の変換比較モードと複素ベクトル表示
- レベル1モジュラー形式図鑑: 重さ k ごとの E4^a E6^b、q展開、ミニ模様
- 図鑑のミニ模様クリックで、同じ基底を大きいモジュラー模様パネルへ表示
- レベル N / Γ0(N) の条件確認モードと領域スケッチ
- Γ0(N) の index、行列判定、代表元サンプル、タイル色分け、cusp、N=1..6 の小例
- Γ0(N)\SL2(Z) を primitive な下段 (c,d) mod N の射影同値類 P^1(Z/NZ) として表示
- レベルN領域は D = union σ_i^-1(F) として描画し、τ_Γ0 は最後に T 正規化して基本ストリップへ戻す
- 右側ステージラベル、Γ0(N) の index/P^1/tile 数検算、tile/representative/function 色モード
- patternCanvas の PNG 保存と、τ・モード・N・模様設定の URL クエリ保存/復元
- SL2(Z) 行列入力と τ への適用モード
- 楕円曲線 y^2 = x^3 + ax + b の実数グラフ、有限体点、判別式、j 表示
- 楕円曲線モードで p=2,3,5,...,31 の #E(F_p)、bad prime、a_p、実験的な f_E(q) 近似、a_p 棒グラフを表示
- 直感、もう少し詳しく、数式の3段階メモ
