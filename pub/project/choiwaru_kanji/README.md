# Choiwaru Kanji

文字・部首・図形を組み合わせて創作漢字を作る、ビルド不要の静的Webアプリです。
`editor.html` で編集、`demo.html` で文章への埋め込みを試せます。

## 起動と公開

このフォルダーで以下を実行し、`http://localhost:8765/` を開きます。

```sh
python -m http.server 8765
```

GitHub Pages等にはフォルダーごと配置してください。サーバー側のプログラムは不要です。
ファイルを直接開いても基本編集はできますが、辞書のfetchはHTTP経由で利用してください。
`index.html` はエディタへの入口です。

## ホームページでの配布

公開用一式は `pub/jssproject/0039/` に配置しています。`downloads.html` に一括ZIP・個別ファイルの配布リンクと設置手順があります。エディタの03とフッター、表示サンプルから開けます。
更新元は `pub/project/choiwaru_kanji/` です。更新後、このフォルダーの `python build-release.py` を実行すると、配布ZIPと0039のコピーを再作成します（指定した配布ファイルのみ上書きします）。サーバーへのアップロードは別途必要です。
配布ZIPにはサンプル辞書を含みます。利用者のlocalStorage内の辞書は含まれないため、エディタで「辞書JSON」を書き出して配置してください。

## つくる

1. 文字欄に複数の文字を入力し、「重ねる・左右・上下・格子」から配置を選んで追加します。空白は区切りとして除外されます。最大256部品です。
2. キャンバス上、または左のレイヤー一覧で部品を選択します。重なって選びづらい部品は一覧から選べます。
3. ドラッグ、またはX・Yの数値で移動します。キャンバスにフォーカスした状態で矢印キーを押すと1、Shift併用で10移動します。スナップはドラッグ時に25単位です。
4. 幅・高さは独立して指定でき、回転と左右・上下反転もできます。座標は常に1000×1000です。文字のインクの境界を測って指定枠に変形するため、一・丶等の小さい部品も枠いっぱいに配置できます。
5. 「文字の太さ」は100〜900のフォントウェイト。「線幅・文字の追加の太さ」は文字・図形の輪郭を太らせ、直線では線幅を指定します。文字の追加線幅は変形前の1000pxの字形に適用されるため、縦横の縮尺により見た目が変わります。図形には変形後の内部座標単位で適用されます。
6. 「前面へ・背面へ」は1段ずつ並べ替えます。消去領域はそれより下の全レイヤーに作用し、上のレイヤーには作用しません。白塗りではなくSVGマスクで透明化します。
7. 戻す・やり直す（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z）は部品とメタデータの直近100操作が対象です。履歴自体は再読み込みでリセットされます。

### 複数部品の移動と複製

登録済みの字を今のキャンバスへ追加するには、04の選択欄で字を選び「選択した字を作業領域に追加」を押します。一覧のクリック操作を「作業領域に追加」に切り替えて、字形タイルから直接追加することもできます。今の字・ID・メタデータは維持され、登録字の部品を同じ座標・サイズで前面へコピーしてまとめて選択します。元の登録字とは独立した部品なので、追加後に変更しても元の辞書項目には影響しません。消去領域も通常のレイヤーとして追加され、既存の下側レイヤーにも作用します。

右の「選択した塊を伸縮」で、横・縦の倍率をそれぞれ1〜1000%で指定して適用できます。横を50%、縦を100%にすると、塊の左上を固定して横だけ半分にします。回転・反転した文字、図形、線幅、消去領域、部品間の間隔も同じ変形を受けます。選択枠の大きさは線の外側へのはみ出しを除いた部品枠の合計です。適用後は倍率欄が100%に戻ります。Undo・Redoに対応します。
全体伸縮は各部品の追加変形として保存するため、従来の幅・高さ欄は変形前の値を表示します。JSONでは任意属性 `matrix: [a, b, c, d]` を使い、部品中心の周囲に追加の線形変換を適用します。このデータを表示するサイトでは、今回の更新後の `kanji-core.js` を使用してください。

Shift / Ctrl / Cmdを押しながらキャンバスやレイヤー一覧の部品をクリックすると、選択を追加・解除できます。「複数選択モード」や「全選択」も使えます。選択した部品は緑の枠で表示します。
複数選択モードをオフにして選択済みの部品をドラッグすると、全体が同じ距離だけ動きます。スナップ時も部品同士の間隔は保たれます。矢印キー、移動量付きの上下左右ボタン、X・Y入力でもまとめて移動できます。複数選択中のX・Y入力は最後に選んだ基準部品の座標です。サイズなど他のプロパティと重ね順は単独選択して編集してください。

キャンバスにフォーカスがある状態でCtrl/Cmd+C → Ctrl/Cmd+Vを押すと、選択部品を同じ座標・大きさ・回転・色のまま前面に複製します。選択部品同士の重ね順も維持します。貼り付け直後は元の部品と重なるため、そのままドラッグか矢印キーで移動してください。貼り付け・削除・移動はいずれもUndoできます。Ctrl/Cmd+Aは全選択です。
「部品をコピー」「部品を貼り付け」ボタンはページ内の一時コピーを使います。入力欄の通常のコピー＆ペーストには干渉しません。キーボードコピーは識別子付きJSONをクリップボードへ保存するため、別のChoiwaru Kanji編集画面にも貼り付けできます。

円は幅と高さを変えると楕円になります。直線は水平を基準とし、回転で傾けられます。
キャンバス下の「比較用の字を重ねる」で、任意の漢字を半透明のピンク色で表示できます。先頭の1文字をNoto Sans JP・ウェイト400・1em（内部座標1000単位）で中央に置き、文字本来の余白を保ちます。部品のように描画領域を引き伸ばしません。不透明度は5〜60%で調整でき、表示中も通常どおり部品を操作できます。比較設定はブラウザに保存されますが、比較用の字はレイヤー・辞書JSON・SVG書き出し・03のプレビューには入りません。
標準はNoto Sans JP。部品ごとにNoto Serif JPも選べます。プレビューの書体変更は保存データを変更しません。

03の例文は自由に編集できます。`{字}` の位置に編集中の漢字が入り、「この字を挿入」でカーソル位置にも追加できます。複数箇所・改行に対応し、例文は下書きと一緒にブラウザ内に保存します（辞書JSONには含みません）。
03の「本文と同じ色」ボタンをオンにすると、プレビュー内の漢字全体を例文の文字色に揃えます。背景を変えた場合も追従し、オフにすると部品ごとの色に戻ります。設定はブラウザ内に保存され、字形・辞書・SVG書き出しの色には影響しません。
04のIDSボタンは、左右・上下・囲み・重ね合わせなど12種の構成記号を入力欄のカーソル位置に挿入します。選択範囲があるときは置換します。部品の文字は続けて入力してください。IDS入力は字形を自動生成するものではありません。

## 保存・読み込み

- 下書きと辞書はこのブラウザのlocalStorageに保存します。端末やブラウザをまたぐ同期はありません。
- 「辞書に保存」は指定IDに追加・上書きします。IDは英数字で始まる英数字・ハイフン・アンダースコア80文字以内です。別IDで保存すると元の字を残したまま追加されます。
- 「辞書JSON」は編集中の字も辞書に保存してから、辞書全体をダウンロードします。ただし、削除済みのIDの下書きや空の下書きは追加しません。
- 読み込みは型・値を検証し、成功時に辞書を置き換えます。元の辞書は `dictionary-backup.json` としてダウンロードします。編集中の下書きはそのまま残ります。
- 登録済みの字を選んで「編集」を押すと再編集できます。元の下書きにはUndoで戻れます。
- 登録字はIMEパッド風の字形一覧でも選べます。1ページ64字で、ページ切り替えとID・読み・意味・コピー用文字列などの検索に対応します。一覧の字を押すと再編集できます。
- 登録字を一覧または選択欄で選び、「選択した登録字を削除…」を押すと、字形・ID・読みを示す確認画面が開きます。「キャンセル」またはEscapeで中止し、「削除する」でこのブラウザの辞書から削除します。削除はUndo対象外です。下書きは残り、JSON書き出しでも削除済みの字は自動で再登録されません。再登録する場合は明示的に「辞書に保存」を押してください。削除状態は再読み込み後も維持されます。
- 公開サイトの辞書はブラウザから直接上書きできません。書き出した `dictionary.json` を配置し直してください。
- 「SVG」は透明背景の字形を書き出します。フォントのアウトラインではなくSVGのtextを使うため、閲覧環境に対象フォントが必要です。

## TTFフォントの生成（05）

1. 字を「辞書に保存」して、05の割り当て一覧を開きます。対象は辞書内の全字です。下書きは先に登録してください。
2. 各字の割り当て位置に `U+E000` / `0xE000` / `E000` のような16進数、または実際の1文字を入力します。既存の文字の位置も、基本・補助私用領域も指定できます。
3. 「割り当てを確認」で未指定・重複・不正値を検査します。該当字は赤枠と理由を表示します。一件でもあればTTFの生成を停止します。制御文字、サロゲート、非文字、Unicode範囲外は指定できません。
4. 「未指定の字を私用領域に連番割り当て」は、指定した私用領域内で、使用済みの位置を避けて空欄だけを埋めます。勝手には割り当てません。「Unicode対応から未指定分を設定」も明示的な操作です。
5. フォント名を指定し、「TTFを生成・プレビュー」を押します。生成TTFをブラウザへ読み込んで表示するため、実際のフォント字形を確認できます。問題がなければTTFとライセンスをダウンロードします。

割り当ては各glyphの任意属性 `fontCodePoint`（整数）として辞書に保存し、ブラウザ内にも保存します。元の `unicode` は「正確に対応する文字」、`fontCodePoint` は「生成フォントで使う配置先」であり別の情報です。割り当て付き辞書JSONを読み込めば配置を再利用できます。生成後に配置・辞書・フォント設定を変更すると、古いダウンロード結果は無効になります。

**輪郭の近似方式と制約：** この初期版は元のベジェ曲線を直接合成する方式ではなく、1024または2048pxのCanvasに描画し、二値化した輪郭を直線のアウトラインとしてTrueTypeのglyfへ保存します。フォント自体はビットマップではありませんが、拡大時には細かな段差が見えることがあります。部品のウェイト・追加の太さ、回転、反転、行列変形、消去、消去後の描き足しを反映します。色は単色に統一し、元の1000×1000枠外は切り取ります。字形が空、未収録の部品文字、輪郭が複雑すぎる場合は該当字を強調して停止します。

固定幅2048 units/em、ascent 1802、descent -246の横書き・ヒンティングなしのTTFです。ルビ・意味・IDS・コピー用文字列はフォントに入りません。フォントを使う文書では割り当てたコードポイントそのものを入力してください。私用領域はこのフォントのない環境では同じ字形を保証しません。

元字形には同梱したNoto Sans JP / Noto Serif JPの可変フォントを使います。生成時に必要な書体のfont-assets/*.jsを読み込むので、HTTPでもfile://でも動作します。未収録文字は代替フォントに切り替えずエラーとします。字形データの出典とSHA-256は `font-assets/SOURCES.json` に記録しています。Noto由来の生成TTFには元の著作権表示とSIL Open Font Licenseをnameテーブルに埋め込みます。配布時はダウンロードしたライセンスも添付してください。予約名Sourceは生成フォント名に使えません。

実装の参照：[OpenType仕様](https://learn.microsoft.com/en-us/typography/opentype/spec/otff)、[Noto Sans JPのOFL](https://github.com/google/fonts/blob/main/ofl/notosansjp/OFL.txt)、[Noto Serif JPのOFL](https://github.com/google/fonts/blob/main/ofl/notoserifjp/OFL.txt)。

## HTMLで表示

```html
<link rel="stylesheet" href="kanji/kanji-renderer.css">
<script src="kanji/kanji-core.js" defer></script>
<script src="kanji/kanji-renderer.js" defer></script>
<script src="page.js" defer></script>

<p>こにゃんは今日も<span data-kanji="gate-cat">⿴門猫</span>していた。</p>
```

`page.js`:

```js
ChoiwaruKanji.init({
  dictionary: "kanji/dictionary.json",
  baseline: "-0.1em",
  ruby: true
}).catch(console.error);
```

パスは利用ページからの相対パスに調整してください。スタイルシートの指定を省いた場合はレンダラーが自身と同じフォルダーのCSSを追加します。

### 表示色をまとめて指定する

```html
<!-- 部品全体とルビをRGBで指定 -->
<span data-kanji="gate-cat" data-color="rgb(210, 65, 90)">⿴門猫</span>

<!-- 既存クラスや親要素のCSS colorに合わせる -->
<span class="accent" data-kanji="gate-cat" data-color="currentColor">⿴門猫</span>
<style>.accent { color: rgb(35, 120, 95); }</style>
```

`data-color` はRGB・16進色・CSS色名などのCSSのcolor値に対応します。`currentColor` はテーマやクラスの変更にも再描画なしで追従します。
ページ全体で統一する場合は `ChoiwaruKanji.init({ dictionary: "kanji/dictionary.json", color: "currentColor" })` のように指定できます。各spanの `data-color` が優先されます。
色指定がない場合や無効な値の場合は辞書の部品色を使います。全体設定から個別に元の色に戻す場合は `data-color="original"` を指定してください。消去マスクと `fill: "none"` はそのまま維持され、辞書の色データは変更しません。

- `ChoiwaruKanji.render(element)`：一要素を再描画。
- `ChoiwaruKanji.renderAll()`：動的に追加した要素を含め、全要素を再描画。
- `init` のdictionaryにはURLのほか、検証対象の辞書オブジェクトも渡せます。
- `data-ruby="hide"` で個別にルビを隠せます。
- クリック・タップ・Enter/Spaceで注釈を開き、Escapeまたは「閉じる」で戻ります。
- 文章のコピー時は創作漢字を `copyText` に置換します。字形・ルビに一部でもかかる選択は、その漢字1字分として扱います。注釈内には単体コピーの操作もあります。
- ページ内の通常テキストは選択された部分を保持し、段落・改行を改行として出力します。複雑な表や独自CSSレイアウトのコピーの完全再現は対象外です。
- 03のプレビューでも、文章をマウスでドラッグして範囲選択し、右クリックメニューの「コピー」またはCtrl/Cmd+Cを使えます。表示中の字形はそのままで、クリップボードへ渡すときだけコピー用文字列になります。表示用ページでも同じ動作です。選択中の文章をドラッグして外部のテキスト欄へ渡す場合も、コピー用文字列を渡します（ドロップ先の対応によります）。字形だけが対象の「画像をコピー」ではなく、文章を選択した上で「コピー」を使ってください。
- 未知のIDや辞書読み込み失敗時は元の代替テキストを保持します。

## データとモジュール

| ファイル | 役割 |
| --- | --- |
| editor.html / editor.css / editor.js | エディタ・保存・プレビュー |
| dictionary.json | サンプル辞書（2字） |
| kanji-core.js | 検証・字形変形・SVGマスク |
| kanji-renderer.js / kanji-renderer.css | インライン表示・ルビ・注釈・コピー |
| demo.html / demo.js | 日記への利用例 |
| browser.test.cjs | ブラウザ上の機能回帰テスト |

辞書は仕様書v0.1の `schemaVersion: "1.0"`、`unitsPerEm: 1000` に対応します。
標準レイヤーに加えて `line` と `circle`、以下の任意属性を扱います。

```json
{
  "type": "text", "char": "猫",
  "x": 100, "y": 100, "width": 800, "height": 800,
  "rotation": 0, "flipX": false, "flipY": false,
  "font": "sans", "fontWeight": 400, "strokeWidth": 0, "fill": "#111827"
}
```

`font` は `sans` または `serif`。省略時はsansです。色は16進色・`currentColor`・`none`を受け付けます（エディタのカラーピッカーは16進色を編集します）。
IDSは文字情報として保存し、字形の再現には必ずlayersを使用します。Unicodeは確認した1コードポイントのみ手動登録してください。

## 制約と今後

フォントはGoogle FontsのCSS経由で読み込みます。ネット接続できない環境ではフォールバックの字形になります。完全なオフライン固定にはフォントを別途配置し、CSSを変更してください。
描画時には文字の計測を行うため、フォントによって見た目は変わります。

本実装はPhase 1とPhase 2の主要機能と、輪郭近似によるTTF生成を実装しています。IDSの自動解析、創作漢字の再帰参照、辞書の統合、自由形状消去、元曲線を維持した正確な輪郭合成、縦書きは未実装です。辞書は5000字、JSON入力は10MBまでです。20字以上も同じ仕組みで保存できますが、同梱サンプルは2字です。

## 検証

PlaywrightとMicrosoft Edgeがある環境でHTTPサーバーを起動し、次を実行します。

```sh
node browser.test.cjs http://127.0.0.1:8765
node interaction.test.cjs http://127.0.0.1:8765
node font.test.cjs http://127.0.0.1:8765
```

複数部品、太さ・反転、Undo/Redo、JSON往復、下書き復元、消去の透明度と重ね順、不正入力拒否、モバイル幅、コピーの選択境界、キーボード注釈操作を検証します。
実機のSafari/Firefoxやタッチ操作は別途確認が必要です。
