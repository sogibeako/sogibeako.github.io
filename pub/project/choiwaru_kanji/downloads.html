エディタ、表示用JS・CSS、サンプル辞書、表示サンプル、説明書をまとめています。解凍したフォルダーをサイトに配置してください。

配布版：2026-10-26 · TTF生成対応

ZIPの辞書は配布用サンプルです。ブラウザ内で作った字は含まれません。エディタの「辞書JSON」で自分の辞書を書き出してください。TTF生成用のNoto Sans JP・Noto Serif JPとライセンスを同梱するため、以前の配布版より容量が大きくなっています。通常の文章表示だけなら下の4ファイルで利用できます。

表示に必要なファイルを個別に保存

  • kanji-core.js ↓ — 字形の生成・変形・消去マスク
  • kanji-renderer.js ↓ — 文章内の表示・ルビ・注釈・コピー
  • kanji-renderer.css ↓ — 表示スタイル・フォントの読み込み
  • dictionary.json ↓ — サンプル辞書（自作の辞書に置き換え可能）

この4ファイルを同じフォルダーに置きます。以下では、そのフォルダーを kanji/ として説明します。

リンクがブラウザ内で開く場合は、リンクを右クリックして「名前を付けてリンク先を保存」を選んでください。

自分のページに組み込む

  1. 表示用の4ファイルを、自分のサイトの kanji/ に配置します。
  2. エディタの「辞書JSON」で書き出したファイルを kanji/dictionary.json に置きます。
  3. HTMLに以下を追加します。パスはそのHTMLから見た位置に合わせて調整してください。
<!-- head内 -->
<link rel="stylesheet" href="kanji/kanji-renderer.css">
<script src="kanji/kanji-core.js" defer></script>
<script src="kanji/kanji-renderer.js" defer></script>
<script src="kanji-init.js" defer></script>

<!-- 本文内：gate-catを自分の漢字IDに変更 -->
<p>今日も<span data-kanji="gate-cat">⿴門猫</span>していた。</p>

HTMLと同じフォルダーに kanji-init.js を作り、次を保存します。

ChoiwaruKanji.init({
  dictionary: "kanji/dictionary.json",
  color: "currentColor", // 周囲の文字色に合わせる
  ruby: true,
  baseline: "-0.1em"
}).catch(console.error);

部品ごとの保存色を使う場合は color の行を省略します。字ごとに色を指定したい場合は次のように書けます。

<span data-kanji="gate-cat" data-color="rgb(210, 65, 90)">⿴門猫</span>
<span class="accent" data-kanji="gate-cat" data-color="currentColor">⿴門猫</span>

辞書の読み込みはHTTP/HTTPS経由で確認してください。ファイルを直接開くとブラウザの制限で読み込めない場合があります。サイトにアップロードするか、解凍したフォルダーで python -m http.server 8765 を実行して http://localhost:8765/ を開けます。

エディタには表示用の4ファイルと、下記のフォント生成ファイルも必要です。一式ZIPの利用をおすすめします。

  • ttf-writer.js ↓ / kanji-font.js ↓ / font-export.js ↓
  • Noto Sans JP字形データ ↓ / Noto Serif JP字形データ ↓（font-assetsフォルダーに配置）
  • Sansライセンス ↓ / Serifライセンス ↓ / 字形データの出典・ハッシュ ↓

05で字ごとのUnicode割り当てを指定し、TTFを生成できます。未指定・重複は赤く表示し、生成を停止します。私用領域への連番割り当ても選べます。初期版は描画を単色化した輪郭近似方式です。元フォントの曲線を直接合成するものではありません。
