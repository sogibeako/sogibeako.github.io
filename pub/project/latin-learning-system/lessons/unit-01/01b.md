# 1B 長母音・音節・音節量

## この小節の目標

この小節を終えると、長母音記号を見分け、初級語を音節に分け、母音の長短と音節量を区別できます。

## 母音の長短

母音には長いものと短いものがあります。この教材では、長い母音に横棒の長母音記号（マクロン）を付けます。たとえば `a` と `ā` は区別されます。

長母音を問う問題では、記号の有無を採点します。それ以外の意味・文法問題では、長母音記号がなくても正答として扱うことがあります。問題ごとに目的が違うためです。

## 音節に分ける

音節は、ひとまとまりとして発音される単位です。初歩では、母音または二重母音の数を手掛かりにします。

- 一つの子音が母音の間にあるときは、通常、後ろの母音と組になります。`Rō-ma`
- 二つの子音が母音の間にあるときは、初歩では間で分けます。`ter-ra`

複雑な子音群や例外は、今は扱いません。

## 母音の長短と音節量は別

音節量とは、音節を「長い」「短い」と数えるための性質です。

- 長母音または二重母音を含む音節は、母音そのものの性質によって長くなります。これを初歩では「本性によって長い」と呼びます。
- 短母音の後ろに二つの子音が続く音節は、位置によって長くなります。このとき母音そのものが長母音になるわけではありません。

`Rō-ma` の最初の音節は `ō` が長母音です。`ter-ra` の最初の音節は、`e` は短母音でも、後ろの二子音によって音節が長くなります。

## 長母音記号は編集上の助け

古代ローマ人の通常の表記で、すべての長母音に現在のマクロンが印刷されていたわけではありません。学習書や辞書は、長短を学びやすくするために記号を補います。後では、記号のない校訂本文にも慣れます。

## まとめ

- 長母音記号は母音の長さを示します。
- 音節の区切りと音節量は別の判断です。
- 短母音を含む音節でも、位置によって長くなることがあります。
- 長母音記号のない本文もあります。
