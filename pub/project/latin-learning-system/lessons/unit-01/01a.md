# 1A 文字と基本の読み方

## この小節の目標

この小節を終えると、初級教材で使うラテン文字を見分け、`i/j` と `u/v` の表記の違いを説明できます。また、復元古典式の基本的な音価を、文字と対応させられます。

## 復元古典式とは

この教材では、古典期の発音を研究にもとづいて再構成した「復元古典式」を標準にします。古代の録音はないため、完全に同じ音を再現できるという意味ではありません。日本語の仮名も補助にすぎません。必要な所では国際音声記号（IPA）を併記します。

## 文字と音を分けて考える

文字は書かれた形、音価はその文字が表す音です。初めは次の対応を使います。

| 表示 | 基本音価 | 注意 |
| --- | --- | --- |
| `c` | /k/ | `caesar` の `c` も硬い音です。 |
| `g` | /g/ | 常に基本的な /g/ として扱います。 |
| `s` | /s/ | 母音の間でも /z/ にしません。 |
| 子音の `i` | /j/ | 日本語の「ヤ行」に近い音ですが、同一ではありません。 |
| 子音の `u` または `v` | /w/ | 版によって字形が変わります。 |
| `qu` | /kʷ/ | 一まとまりの子音として読みます。 |

## `i/j` と `u/v`

古典期の文字体系では、`I` は母音と子音の両方、`V` は母音と子音の両方を表しました。現代の版には、子音を `j` と `v` で書き分けるものもあります。

この教材の内部データは見出し形を一つにそろえますが、入力では問題の目的を壊さない範囲で `i/j` と `u/v` の差を許します。たとえば `iuvenis` と `juvenis` は、表記の違いとして対応づけられます。

> 補足：すべての校訂本文が同じ書き方を使うわけではありません。版の方針を確認しましょう。

## 読む練習

`Rōma`、`vir`、`iūs`、`Caesar` を、表の対応を指で追いながら読んでみましょう。長母音記号とアクセントの規則は1B・1Cで学びます。ここでは完全な発音判定を行いません。

## まとめ

- 文字と音価は別の情報です。
- 復元古典式は、古典期の発音の研究上の再構成です。
- `i/j`、`u/v` は、版によって異なる表記として現れます。
- 仮名だけでラテン語の音を完全には表せません。
