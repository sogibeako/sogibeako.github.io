# AGENTS.md

## この文書の目的

このファイルは、会話履歴を参照できない将来の作業者を含め、本プロジェクトで作業する人間およびCodexが守る規則を定める。

本プロジェクトは、日本語母語話者向けの古典ラテン語教材を、一括生成ではなく反復的に開発・検査・改善するためのシステムである。

## 作業範囲

- 作業対象は、この `latin-learning-system` ディレクトリ以下に限定する。
- 親ディレクトリや既存ホームページのファイルを変更してはならない。
- 既存ファイルを無断で上書き、削除、移動してはならない。変更前に内容と既存作業を確認する。
- 一回の依頼では、明示的に指定されたマイルストーンだけを実行する。
- 現在位置と各マイルストーンの状態は `PLANS.md` を正本として確認する。
- 指定されたマイルストーンの合格条件を満たすまで、次のマイルストーンへ進まない。
- コミット、プッシュ、公開、デプロイは、明示的な依頼なしに行わない。

## 教材とプログラムの分離

- 教材本文は原則としてMarkdown、問題・語彙・例文等の構造化データは原則としてJSON、表示はHTML/CSS/Vanilla JavaScript、検査と静的生成はPython 3として分離する。
- 課程と技能依存関係は、指定されたYAMLファイルで管理できる。
- 教材本文、問題データ、表示プログラムのいずれかへ、他の層の正本を埋め込まない。
- 配布時にデータをHTML等へ埋め込む場合も、生成元の正本は分離して保持する。
- 外部依存関係を無断で追加しない。追加が必要な場合は、目的、代替案、保守上の影響を記録し、依頼者の承認を得る。

## 課程・技能・語彙

- 英語の単元をラテン語へ機械的に一対一対応させない。
- 英語教育からは、段階づけ、説明の粒度、復習間隔、反復、技能統合などの学習設計原則を抽出する。
- ラテン語の学習順序は、語形論・統語論・読解技能等の依存関係から設計する。
- 単元で許可されていない未習技能や未導入語彙を、本文、例文、問題へ無断で使用しない。
- 未習要素を意図的に提示する場合は、その教育目的、扱い方、注釈を明示し、判断を `logs/decisions.md` に記録する。
- 問題は、採点対象、許容解、正規化規則、曖昧になり得る別解析を追跡可能にする。
- 自動採点問題は、正答が一意に定まることを自動検査と人間確認の両方で保証する。

## 出典と根拠

- 文法事項、例文、問題について、出典または生成根拠を追跡可能にする。
- Codexが直接確認できない紙資料等は、依頼者から該当箇所と書誌情報が提供されない限り、Codexによる確認済み根拠として扱わない。
- 引用は必要最小限とし、書誌情報、引用元、利用条件、改変の有無を記録する。
- 著作権で保護された資料の長大な転載を `sources/excerpts/` その他の場所へ保存しない。
- 時代、文体、レジスターを記録し、古典ラテン語と後期・教会ラテン語の用法を無意識に混在させない。

## 確認状態と人間承認

- `draft` は制作状態として扱う。
- `source-checked`、`editorial-approved`、`expert-reviewed` は、互いに独立した確認記録として扱う。一つの順序付き状態へ統合しない。
- 各確認記録には、確認者、確認日、対象版または対象内容、必要に応じて注記を持たせる。
- Codex自身による確認を `expert-reviewed` として扱わない。
- 外部の人間のラテン語専門家が確認していない内容を `expert-reviewed` として記録しない。
- ラテン語の正確性、訳の妥当性、説明の平易さ、問題の意味的な一意性など、人間判断を要する項目は自動検査だけで承認しない。

## 品質・検査・記録

- テストや検査の失敗を残したまま、そのマイルストーンを完了としない。
- 検査を実行できない場合は、理由、影響、残るリスクを記録し、合格扱いにしない。
- 判断が必要な設計変更は、選択肢、決定、理由、影響、再検討条件とともに `logs/decisions.md` に記録する。
- 各反復の変更内容、検査方法、結果、発見事項、次の修正候補を `logs/iteration-log.md` に記録する。
- 問題修正時は、可能な限り再発防止となる規則または回帰テストを追加する。
- 自動検査結果と人間による承認結果を混同しない。

## ライセンス

- 現時点でプロジェクトのライセンスは未確定であり、自動的にライセンスファイルやライセンス表示を設定しない。
- プログラム、オリジナル教材本文、問題データ、引用・翻案した例文、外部素材は、将来個別にライセンスを検討できるよう区別する。
- 第三者素材について、出典、ライセンス、改変可否、商用利用可否を記録する。
