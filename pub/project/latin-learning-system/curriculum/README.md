# curriculum

英語教育の参照整理、一般的な学習原則、ラテン語技能依存関係、課程への割り当てを置くディレクトリ。M2で第1～第5単元に必要な技能DAGと課程マップを暫定作成した。

予定ファイル：

- `english-reference.md`：M1で作成した英語教育資料の観察と非移植事項
- `learning-principles.md`：M1で作成した14の学習設計原則
- `latin-skill-map.yml`：M2の技能ノード、強い前提、推奨順、並行導入、独立レビュー状態
- `curriculum-map.yml`：M2の5単元・15小単元、負荷上限、語彙条件、復習配置、出口条件

M2のYAMLは、外部ライブラリを追加せず検証できるようJSON互換のYAML 1.2構文で記述している。正式スキーマはM3で確定する。
