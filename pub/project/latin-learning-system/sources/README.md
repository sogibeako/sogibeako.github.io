# sources

出典方針、書誌情報、利用条件、教材項目との参照関係を管理するディレクトリ。M1で出典運用方針、暫定書誌、ラテン語資料候補の比較を作成した。

- `source-policy.md`：確認範囲、引用・要約・翻案、権利、`source-checked` の規則
- `bibliography.json`：M3まで変更可能なM1暫定書誌
- `latin-source-comparison.md`：ラテン語資料の用途・弱点・権利・採用提案
- `excerpts/`：許される場合でも必要最小限の短い引用だけを置く場所
- `records/`：M3以降、個別レコードを分割する必要が生じた場合の候補。現時点の書誌正本は `bibliography.json`

長大な転載は保存しない。引用が必要な場合は必要最小限とし、出典、利用条件、改変の有無を記録する。
