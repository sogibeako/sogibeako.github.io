# 品質評価表

## 1. 判定原則

必須ゲートと段階評価を分離する。必須ゲートが一つでも失敗すれば、尺度の平均が高くても承認できない。尺度の単純平均で重大な欠陥を相殺しない。

## 2. 必須ゲート

| ID | 合格条件 | 主な判定者 |
|---|---|---|
| G-01 | ラテン語本文・語形・解析・規則に確認済みの重大誤りがない | 人間＋出典 |
| G-02 | 未習技能・未導入語彙の無断使用がない | M4＋人間 |
| G-03 | 自動採点の正答・不正答・選択肢が正規化後に衝突しない | M4＋人間 |
| G-04 | 必要な出典または独立生成根拠があり、claim scopeと対応する | Schema＋人間 |
| G-05 | review状態・確認者・対象版が偽装されず、旧版承認を現行扱いしない | M4 |
| G-06 | 引用、電子化、ライセンス、商用利用条件に重大な未処理リスクがない | 人間 |
| G-07 | 必須フィールド、ID、参照、Schemaが完全 | Schema＋M4 |
| G-08 | 自動採点不能な形式をautomatic scoringしていない | Schema＋人間 |
| G-09 | 予告・未分析・正式導入が区別され、予告を習得済みにしていない | Schema＋M4 |
| G-10 | アクセシビリティ上、色・視覚配置だけが唯一の情報源でない | 人間＋将来ブラウザ検査 |

## 3. 1～5評価尺度

共通定義：1は利用不能、2は大幅修正、3は試作可能だが改善要、4は対象に適合、5は再利用可能な模範水準。各項目は以下の観察基準で評価する。

| 項目 | 1 | 3 | 5 |
|---|---|---|---|
| 説明の平易さ | 定義なし・飛躍が多い | 定義はあるが一部再読が必要 | 初出定義、短い論理段階、誤解範囲も明示 |
| 新出事項の負荷 | 複数概念を同時に要求し出口未達 | 暫定上限内または理由ある警告域 | 十分な練習時間があり再出まで成立 |
| 例文の分かりやすさ | 未習・曖昧要素が支配的 | 解析可能だが注釈がやや多い | 目的技能が明瞭で既習語彙中心 |
| 自然訳 | 意味・文体が不適切 | 妥当だが硬い部分がある | 文脈に自然で構造説明とも整合 |
| 構造対応訳 | 逐語置換で関係が見えない | 主要関係は見える | 主要関係が明瞭で自然訳との差も有用 |
| 問題の教育価値 | 当て推量・未習依存 | 技能を測るが転移が弱い | 対象技能を明確に検索・適用させる |
| フィードバック | 正誤だけ | 誤り種別または確認技能を示す | 誤概念、理由、次の行動を簡潔に示す |
| 復習配置 | 初出後に再出なし | 次単元または間隔復習あり | 誘導、次使用、間隔、累積、出口が連動 |
| レジスター | 時代・文体不明 | ラベルはある | 出典・生成根拠と用法が古典散文範囲で整合 |
| アクセシビリティ | 視覚・色だけに依存 | 基本ラベルはある | 見出し、表、注記、印刷、読み上げを一貫配慮 |
| 達成感 | 出口が不明・急峻 | 目標と確認が対応 | 小さな達成、累積使用、次の見通しが明瞭 |

段階2は「段階1の致命的状態は一部解消したが、段階3の観察条件を一つ以上満たさない」、段階4は「段階3の条件をすべて満たし、段階5の条件を一つ以上満たすが全部は満たさない」と判定する。評価者は、満たした条件と不足条件を `notes` に列挙する。これにより2と4も観察可能にし、印象だけで中間点を付けない。

## 4. M2負荷上限のM3運用

M2値は最終基準ではない。M3では次の運用ゲートとする。

- 通常域：新出技能1～5、語彙は発音0～6・文法0～8・累積準備0～10、M2文長内。
- 警告域：新出技能6、語彙上限ちょうど、複数の新形態体系を同時導入、または想定時間70分を超える見込み。
- 原則不合格：技能7以上、上限超過、未習注釈でしか成立しない、出口条件が一回の学習時間で測れない。
- 例外承認：分割すると依存理解を損なう理由、支援策、練習時間、出口条件、人間承認、M6再評価指標を記録する。

## 5. M2の個別警告

- 2Bの6技能：警告域。用語定義と構造分析を分け、45～70分で不足なら分割候補に戻す。
- 3Aの主格・対格単複：誤答が格と数の両軸で集中する、表の再現が分析を圧迫する場合は分割する。
- 3B・5Aの活用類数：3Bは例示する活用類を2種程度から試し、5Aでも一度に全類型を独立生成させない。最終数は人間確認。
- 4Cの形容詞と一致：形容詞形と一致関係の二重負荷。特徴選択ができても文中修飾を誤る場合は練習段階を分ける。
- 5Cの辞書初導入：辞書記号の理解が読解時間を支配する場合、5B以前の予告または5C分割を再検討する。
- 累積読解の新語10：上限であり目標ではない。未知語注釈が一文に複数必要、既習構造の検索を阻害する場合は減らす。

## 6. M6で再評価する指標

想定時間内完了率、出口達成率、誤答カテゴリ分布、ヒント使用率、再学習回数、未習注釈数、読解一文当たり停止回数、自己評価と客観結果の差、説明の再読報告を記録する。数値閾値は実測前に最終決定しない。
