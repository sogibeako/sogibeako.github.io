# 翻訳規約

## 1. 翻訳関連の層

- `token_annotations`：語ごとのlemma、形態、統語機能、必要最小限の語義。
- `structure_aligned_translation`：主語・述語・目的語・修飾等の対応が見える教育用の日本語。
- `natural_translation`：通常の日本語として読める訳。
- `reading_explanation`：省略、係り受け、語義選択、語順変更を説明する文章。
- `model_translation`：自己評価課題で比較する一案。
- `acceptable_alternatives`：構造と文脈に適合する別訳。

## 2. 構造対応訳

ラテン語構造を可視化する教育用表現であり、語順を機械的に逐語置換したものではない。ラテン語の統語関係を誤る不自然さは許さない。自然な日本語でないことを唯一の正解条件にしない。

## 3. 自然な訳

文脈に応じ、主語補充、語順変更、省略の補い、語義選択、名詞表現と動詞表現の調整を許す。変更した関係は読解説明で追跡できるようにする。構造分析の正誤と、日本語表現の自然さ・文体は別軸で評価する。

## 4. 評価

- tokenの解析、主要構造、語義範囲は個別に確認する。
- 自然訳が異なっても同じ妥当な構造分析を持つ場合がある。
- 構造対応訳が近くても、係り受けや格機能を誤っていれば不正解である。
- 完全な羅文和訳は初期版で一意自動採点しない。模範訳、別訳、構造チェック、自己評価項目を提示する。
- 翻訳の `source-checked`、日本語編集、専門家確認は独立する。

## 5. 省略主語

動詞語尾と文脈が支える範囲で日本語へ補える。ラテン語本文に明示されない代名詞をtokenとして捏造せず、`reading_explanation` と統語上のimplicit subjectに記録する。複数の主語候補が残る場合は一意訳として自動採点しない。
