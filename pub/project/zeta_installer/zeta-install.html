zetaの会話をTXTに保存

このボタンをChromeのブックマークバーへドラッグしてください。バーの表示切り替えは Ctrl + Shift + B です。

zeta TXT保存

  1. zetaで保存したい会話を開き、最新の発言まで移動します。
  2. 登録した「zeta TXT保存」をクリックします。
  3. 自動で対象を見つけられない場合は、会話の本文を1か所クリックします。
  4. このタブを表示したまま待つと、過去へスクロールしてTXTをダウンロードします。「ここまでを保存」で途中保存もできます。

試用版：提供されたHTMLには会話本文が含まれていないため、実際のzeta画面での検証は未実施です。約16秒間読み込みと位置の変化がない場合に停止します。全文取得は保証できません。メニュー等の混入、重複、欠落、順序を保存後に確認してください。同じ文が続く箇所や読み込みが遅い場合は特に注意してください。

本文はページ内で処理して端末へ保存します。このコードによる外部送信はありません。スクロールに伴うzeta自身の読み込みは発生します。収集中は会話を切り替えず、新しい発言の送信も避けてください。

ドラッグできない場合：ブックマークのURLへ貼り付けるコード

任意のブックマークを作成し、「編集」でURLを下の全文に置き換えます。
