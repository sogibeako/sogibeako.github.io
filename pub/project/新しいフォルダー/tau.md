# Webアプリ仕様書

## **τの庭：モジュラー形式を直感するための可視化アプリ**

一彌「上半平面に庭を作るぞ！」
一埜「数学の庭園、ちょっと怖いけど楽しそう！💦」

---

## 1. コンセプト

**τの庭**は、モジュラー形式をいきなり数式で理解するのではなく、

[
\tau
\longleftrightarrow
\text{格子}
\longleftrightarrow
\text{トーラス}
\longleftrightarrow
q
\longleftrightarrow
\text{モジュラー形式}
]

という対応を、ブラウザ上で動かしながら理解するためのWebアプリである。

中心となる操作は、

> 上半平面上の点 (\tau) を動かすと、格子・トーラス・q展開・モジュラー形式の値が同時に変わる

というもの。

---

## 2. 対象ユーザー

### 主対象

* モジュラー形式に興味はあるが、数式だけだと入口で迷子になる人
* 楕円曲線、複素トーラス、上半平面、(q) 展開の関係を直感したい人
* フェルマー最終定理の周辺数学を「雰囲気だけでも掴みたい」人

### 想定レベル

* 複素数 (a+bi) は知っている
* 行列や群は少しだけ聞いたことがある
* 楕円曲線やモジュラー形式はよくわからない
* でも動くものを見ると理解が進むタイプ

# 6. ビュー仕様

## 6.1 上半平面ビュー

### 表示内容

* 複素上半平面 (\mathbb H)
* 現在の (\tau)
* 基本領域

基本領域は次で表す。

[
|\operatorname{Re}\tau|\leq \frac12
]

かつ

[
|\tau|\geq 1
]

つまり、だいたい中央にある「丸い底を持つ縦長の領域」。

### 操作

* マウスドラッグまたはタッチで (\tau) を移動
* スライダーでも変更可能
* (\tau) が変化すると、他ビューもリアルタイム更新

### 表示例

```text
τ = 0.32 + 1.18i
|τ| = 1.22
q = -0.00048 + 0.00098i
|q| = 0.00109
```

---

## 6.2 格子ビュー

現在の (\tau) に対して、

[
\Lambda = \mathbb Z + \mathbb Z\tau
]

を描画する。

### 表示内容

* 基底ベクトル (1)
* 基底ベクトル (\tau)
* 格子点

[
m+n\tau
]

ただし、

[
m,n \in \mathbb Z
]

表示範囲内にあるもののみ描画。

### 重要な直感

ユーザーに伝えること：

> (\tau) を動かすと、格子の形が変わる。
> モジュラー形式は、この格子の形に深く関係している。

### 操作

* 格子ビュー自体は基本的に表示専用
* 将来的には格子点をクリックして座標表示してもよい

## 6.3 トーラスビュー

MVPでは簡易表示でよい。

### Phase 1では

平行四辺形の基本領域を表示する。

```text
│       │
│       │
```

辺の貼り合わせを矢印で示す。

* 左辺と右辺が同一視される

### Phase 2以降

* 3Dトーラス表示

* 格子の歪みとトーラスの形状の対応

ただし数学的には複素トーラスの形状を3Dドーナツとして完全に表現するのは慎重に扱う。

## 6.4 qビュー

[
q=e^{2\pi i\tau}
]

を単位円内に表示する。

[
\tau=x+iy
]

なら、

[
q=e^{2\pi ix}e^{-2\pi y}
]

なので、

[
|q|=e^{-2\pi y}
]

である。

### 表示内容

* 単位円
* 現在の (q)
* (|q|)
* (\arg(q))

### 直感

* (\operatorname{Im}\tau) が大きいほど、(q) は0に近づく
* (\operatorname{Re}\tau) を変えると、(q) は回転する
* (q) 展開は、(\tau) よりも (q) で見ると扱いやすくなることがある

一彌「上半平面の点が、単位円の中に吸い込まれていく！」
一埜「虚部が大きいほど、中心に落ちていくんだね」

# 7. 変換機能

## 7.1 T変換

[
T:\tau\mapsto \tau+1
]

ボタン：

```text
[T: τ → τ + 1]
```

効果：

* 上半平面上の点が右に1移動
* 格子は基底の取り方が変わる
* 実は同じ複素トーラスを表している、という説明を表示

---

## 7.2 S変換

[
S:\tau\mapsto -\frac{1}{\tau}
]

ボタン：

```text
[S: τ → -1/τ]
```

効果：

* 上半平面上の点が反転的に移動
* 格子の基底が大きく変わる
* でもやはり同じ複素トーラスを表す

---

## 7.3 基本領域に戻す

ボタン：

```text
[基本領域に戻す]
```

### アルゴリズム案

現在の (\tau) に対して、次を繰り返す。

1. (\operatorname{Re}\tau) が ([-1/2,1/2]) に入るように (T^n) を適用
2. (|\tau|<1) なら (S) を適用
3. 条件を満たすまで繰り返す

擬似コード：

```ts
function reduceToFundamentalDomain(tau: Complex): Complex {
  let z = tau;

  for (let i = 0; i < 50; i++) {
    const n = Math.round(z.re);
    z = sub(z, complex(n, 0)); // T^{-n}

    if (abs(z) < 1) {
      z = div(complex(-1, 0), z); // S
      continue;
    }

    if (Math.abs(z.re) <= 0.5 && abs(z) >= 1) {
      return z;
    }
  }

  return z;
}
```

# 8. q展開パネル

## 8.1 表示対象

MVPでは以下を表示する。

### Eisenstein級数 (E_4)

[
E_4(q)=1+240\sum_{n=1}^{\infty}\sigma_3(n)q^n
]

最初の数項：

[
E_4(q)=1+240q+2160q^2+6720q^3+17520q^4+\cdots
]

---

### Eisenstein級数 (E_6)

[
E_6(q)=1-504\sum_{n=1}^{\infty}\sigma_5(n)q^n
]

最初の数項：

[
E_6(q)=1-504q-16632q^2-122976q^3-532728q^4+\cdots
]

---

### 判別式 (\Delta)

[
\Delta(q)=q\prod_{n=1}^{\infty}(1-q^n)^{24}
]

最初の数項：

[
\Delta(q)=q-24q^2+252q^3-1472q^4+4830q^5+\cdots
]

---

### j不変量

[
j(q)=\frac{E_4(q)^3}{\Delta(q)}
]

正規化された展開：

[
j(q)=q^{-1}+744+196884q+21493760q^2+\cdots
]

## 8.3 計算方法

### 約数冪和

[
\sigma_k(n)=\sum_{d|n}d^k
]

実装：

```ts
function sigma(n: number, k: number): number {
  let sum = 0;
  for (let d = 1; d <= n; d++) {
    if (n % d === 0) {
      sum += Math.pow(d, k);
    }
  }
  return sum;
}
```

### (E_4)

```ts
function E4(q: Complex, terms = 20): Complex {
  let sum = complex(1, 0);

  for (let n = 1; n <= terms; n++) {
    const coeff = 240 * sigma(n, 3);
    sum = add(sum, mulReal(pow(q, n), coeff));
  }

  return sum;
}
```

### (E_6)

```ts
function E6(q: Complex, terms = 20): Complex {
  let sum = complex(1, 0);

  for (let n = 1; n <= terms; n++) {
    const coeff = -504 * sigma(n, 5);
    sum = add(sum, mulReal(pow(q, n), coeff));
  }

  return sum;
}
```

### (\Delta)

MVPでは積表示よりも、最初の既知係数で近似してよい。

```ts
const tauCoeffs = [
  0,
  1,
  -24,
  252,
  -1472,
  4830,
  -6048,
  -16744,
  84480,
  -113643,
  -115920
];
```

```ts
function Delta(q: Complex, terms = 10): Complex {
  let sum = complex(0, 0);

  for (let n = 1; n <= terms; n++) {
    sum = add(sum, mulReal(pow(q, n), tauCoeffs[n]));
  }

  return sum;
}
```

# 9. 解説パネル仕様

画面右下または下部に、現在の操作に応じた短い説明を表示する。

## 9.1 通常時

```text
τ は上半平面上の点です。
この点から格子 Λ = Z + Zτ が作られます。
```

```text

モジュラー群の基本変換のひとつです。
```

## 9.4 q表示時

```text

Im(τ) が大きいほど |q| は小さくなります。
そのため、q展開は上半平面の上の方でよく収束します。
```

# 18. 注意点

## 18.1 数値計算の精度

q展開は (|q|) が小さいとよく収束する。

つまり、

[
\operatorname{Im}\tau
]

が大きいほど計算しやすい。

逆に、(\operatorname{Im}\tau) が小さいと (|q|) が1に近づき、収束が遅くなる。

その場合は警告を出す。

```text
Im(τ) が小さいため、q展開の近似精度が落ちる可能性があります。
```

---

## 18.2 j不変量の発散

(\Delta(q)) が0に近いと、

[
j(q)=\frac{E_4(q)^3}{\Delta(q)}
]

が非常に大きくなる。

表示上は指数表記にする。

```text
j(q) ≈ 1.23e+8 - 4.56e+7 i
```

---

## 18.3 数学的説明の深さ

MVPでは厳密な証明はしない。

説明は三段階にする。

```text
直感
もう少し詳しく
数式
```

例：

```text
直感：
τは格子の形を決めます。

もう少し詳しく：
1とτを基底にして、Z + Zτ という格子を作ります。

数式：
Λ = {m + nτ | m,n ∈ Z}
```

# 20. まとめ

このアプリの核は、

> **モジュラー形式を直接説明する前に、モジュラー形式が住んでいる地形を見せる**

ことです。

モジュラー形式そのものは難しい。
でも、

[
\tau
]

が動くと、

[
\Lambda=\mathbb Z+\mathbb Z\tau
]

が動き、

[
\mathbb C/\Lambda
]

というトーラスが見えて、

[
q=e^{2\pi i\tau}
