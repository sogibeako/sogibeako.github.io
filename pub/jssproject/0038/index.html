計算のしくみと、展開の読み方

式入力は有理数、sqrt(有理数)、√2、底^(指数) に対応します。例：sqrt(2)、2^(1/3)、(3/2)^(-2/3)。底と指数は有理数で、指数は約分後の分子の絶対値・分母が 100 以下です。π・e や式同士の加減乗除には未対応です。負の数の奇数乗根は実数として扱います。

根が有理数なら厳密値を使います。無理数なら幅 10⁻²⁴⁰ の有理数の区間で挟み、上下限から同じ数字を得られる桁だけを確定します。次の桁が確定しなければ表示桁数より手前で止めます。表示した有限桁列の値と、元の無理数は異なります。

桁の逆算欄では、上の展開とは独立して基数を変更できます。基数を変更しても入力した桁列は保持されます。整数部分と符号を含めて、末尾以降を 0 とした値を厳密に計算します。第 n 桁を 1 増やすと、正の数では値が 1/Qₙ 増えます。変化量は元の無限展開ではなく、取り込み時の基数と有限桁列が表す値との差です。

小数部分を r₀ として、aₙ = ⌊qₙrₙ₋₁⌋、rₙ = qₙrₙ₋₁ − aₙ を繰り返します。Qₙ = q₁⋯qₙ とすると、小数部分 = Sₙ + rₙ/Qₙ。表示を打ち切ったときも、残りは厳密な分数で求められます。

rₙ = 0 なら有限展開です。固定基数や繰り返し基数では、基数列の位置と余りがともに再び一致したときに循環を検出します。基数が変わり続ける場合、数字の並びが似ていても循環とは判定しません。

負の数は絶対値を展開し、全体に負号を付けます。整数部分は 10 進表記のまま分離します。有限展開と、最大の数字が無限に続く展開が同じ値を表す場合は、有限展開を採用します。

階乗型では Qₙ = (n+1)!、指数型 qₙ = 2ⁿ では Qₙ = 2⁽ⁿ⁽ⁿ⁺¹⁾/²⁾ です。整数演算で計算しているため、分数表示に丸め誤差はありません。
