組み込みは、JSとspanだけ。

JavaScriptをHTMLと同じフォルダーに置き、次のように読み込みます。加工対象は、文字列を囲んだspanです。

<script src="glitch-text.js" defer></script>

<span data-glitch-method="1,4,7" data-glitch-rate="70">
  この文字をバグらせる
</span>

この例では70％の文字を加工し、各文字に①④⑦のいずれかを使います。フォント・文字サイズ・色は、そのspanのCSSを引き継ぎます。CSSファイルの追加は不要です。

JavaScriptをダウンロード配布ページと使用例をまとめて保存最小の使用例を開く

後から文章や属性を変更する場合

属性を変更したらrefresh()を呼びます。文章の変更にはsetText()を使います。

const span = document.querySelector('#my-glitch');
span.dataset.glitchMethod = '5,6';
span.dataset.glitchRate = '50';
GlitchText.refresh(span);

GlitchText.setText(span, '新しい文章');
GlitchText.reroll(span); // 配置を再生成（seed指定時は固定）
GlitchText.init(container); // 後から追加したspanを初期化
GlitchText.destroy(span); // 元の通常表示へ戻す

一文字分の枠の幅・高さを保って加工します。空白は加工しません。文字の分割はIntl.Segmenter対応ブラウザでは絵文字・結合文字をまとめて扱います。リンクやルビなどを含めず、文字列だけをspanで囲んでください。
