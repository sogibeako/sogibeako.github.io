セリフの編集方法

1. dialogue.js をテキストエディターで開きます。
2. 各 [ ] の中へ、"文章", の形で追加します。
3. UTF-8で保存し、ゲームを再読み込みします。探索は最初からになります。

編集するリスト
floor   : 新しい階層の雰囲気
near    : ミノタウロス隣接時の動作・セリフ
frozen  : 金縛り中の敵の様子
hidden  : 身代わりを追っている敵の様子
mageFreeze  : メイジが金縛りの杖を使用した時
mageBlow    : メイジが吹き飛ばしの杖を使用した時
mageSwap    : メイジが場所替えの杖を使用した時
mageConfuse : メイジが混乱の杖を使用した時
              各4候補。実際に杖の回数を消費した時に1つ表示します。
ariadne : 討伐後のアリアドネのセリフ
bread   : 倒れたキャラクターがパンになる場面
          {name} は「あなた」「ミノタウロス」などに置き換わります。
defeat  : 敗北後、LOGに出るアリアドネのセリフ

追加例（ariadne の [ ] 内）
    "アリアドネ「よくできました。……あれ、パンの数が合わないわ」",
    "アリアドネ「小人さん、焼きすぎには気をつけてね」",

半角の二重引用符で囲み、文章と文章の間に半角カンマを入れます。
セリフのカギ括弧には「」が使えます。文章に半角の二重引用符を使いたい場合は \" と書きます。
リストの名前や [ ]、{ } は消さず、文章の行を編集してください。
空リスト [] にすると、その種類のフレーバーログを省略します。
通常ログの候補はランダムに選ばれ、同じ文章の連続表示は避けます。
ゲームオーバーの既存の見出し・ボタン等はこのファイルでは変わりません。

敗北時の名言は defeat-quotes.js

A       : 1〜2Fで倒れた場合
B       : 杖を拾い、全種使い切って通常攻撃で倒れた場合
C       : 杖を残し、通常攻撃の最大値を超えるHPから痛恨で倒れた場合
D       : 冒険中、初めて受けたメガタウロスの痛恨で倒れた場合
E       : 移動先で、動いていない敵に攻撃されて倒れた場合
default : 上記のどれにも該当しない場合
複数に該当した時の優先順位：D → C → B → E → A → default

各分類の [ ] 内の { ... } 一組が1候補です。
同じ形でコピーし、組と組の間にカンマを入れると候補を増やせます。
    label  : 小見出し
    ja     : 日本語訳
    en     : 引用原文
    credit : 著者・作品・話者など
    url    : 出典の https://... リンク

各分類には現在1候補あります。2候補以上にすると敗北ごとにランダム抽選します。
同じ敗北画面内で名言が変わることはありません。
分類が空の場合はdefaultから選び、defaultも空なら名言欄を表示しません。
実在の名言を追加する際は、原文・著者・出典が一致するよう編集してください。

サウンドテストのコメント
標準コメントは sound-comments.js に、音源のファイル名をキーとして記載します。
例："dungeon_synth1.mp3": "この曲についてのコメント",
コメントは sound-comments.js のみで編集します。ゲーム画面は閲覧専用です。
以前ブラウザーで保存したコメントによる上書きは行いません。


敵にカーソルを合わせたときのフレーバー（dialogue.js）
infoNormal：通常 / infoMega：メガ / infoHero：豪傑 / infoMage：メイジ
infoImmortal：不死 / infoUnderworld：冥界 / infoBuilder：迷宮殺し
infoQuantum：量子 / infoPhantom：量子の幻影 / infoDecoy：身代わり
各リストの文字列を編集・追加できます。同じ個体では同じ文章を表示します。
空のリスト [] にすると、その種類のフレーバーだけを非表示にできます。
能力値などの説明はそのまま残り、左下の情報欄だけに表示されます。
