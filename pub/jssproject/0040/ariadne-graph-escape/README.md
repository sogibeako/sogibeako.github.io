# Ariadne Graph Escape

`index.html` をブラウザーで開くと遊べます。ビルド・インストール不要。フォント取得以外はネットワークを使わず、オフラインでも動作します。

- 矢印：隣接経路を選択。同方向に複数ある場合は繰り返して切り替え。
- Enter：移動または杖の発射。通常移動は隣接ノードのクリックでも実行。杖の準備中は終点クリックで経路を選択し、Enterまたは発射ボタンで確定。
- 1〜4：杖を装備。Esc：解除。
- `>`：階段上で次の階層へ。`.` または自分の `@` をクリック：待機（杖の構えを解除、1ターン経過、歩行と同じHP回復）。
- `?`：ルールを表示。
- AとBを押しながらEnter：デバッグ画面。階層・レベル（1〜999）を指定して全快で新しい探索を開始。杖は金縛り・吹き飛ばし・場所替え・身代わりの順に5・5・5・2回。デバッグ探索は最高得点・ベスト10の対象外です。

画面の「遊び方」にダメージ、スコア、各杖の詳細を収録。階層・HP・所持品はプレイ中のみ保持し、最高得点と名前付きベスト10を localStorage に保存します。ランキングはこのブラウザー・保存元URLごとのローカル記録です。ゲームオーバー後に英数字1〜10文字で1探索につき1回登録でき、同点は先に登録した記録を優先します。

仕様補足：自然回復は最大HPの1%（通常1HP）を歩行・待機時に回復し、小数が出る場合は蓄積。残りHP・レベル・階層によって減衰しません。杖は各階1本、10%の確率で2本。種類の比率は金縛り・吹き飛ばし・場所替え・身代わりが2:2:2:1。身代わりは1〜3回、それ以外は2〜5回。必要討伐数はLV1→2が3体から1体ずつ増加（LV9→10は11体）。LV10未満ではメガタウロス1体を通常の敵3体分として数えます。LV10到達後はメガタウロスのみを1体ずつ新たに数え、LV10→11が3体、LV11→12が4体と増加。各レベルで討伐数をリセットし、過去の討伐は持ち越しません。身代わり化しても元がメガタウロスなら対象です。通常敵も討伐得点・総討伐数には加算します。レベルアップで、最大HP・現在HPが各10、剣の基本ダメージは到達LVが偶数なら1・奇数なら2増加。乱数はLV1〜4が±3、LV5〜14が±4、LV15以降が±5。+3以上で再ヒットし、再ヒットでも条件を満たす限り繰り返します（敵のHPが0なら終了）。杖は角度条件を満たす全分岐の突き当たりを列挙し、候補ボタン・終点クリック・矢印で固定経路を選び、Enterまたは発射ボタンで発射します。敵の位置にかかわらず選んだ経路を維持します。吹き飛ばしは終端（壁）または途中の次の敵まで。壁衝突は10ダメージ、敵衝突は双方に10ダメージ。生存する衝突相手と重なる場合は、その隣接空きノードをノードID順で選びます（射線の直前ノードは最後の候補）。衝突相手が倒れた場合はそのノードへ着地。準備中に命中対象・着地先・ダメージを表示し、衝突した双方はそのターン行動しません。衝突ダメージも実ダメージ得点・討伐点を加算し、金縛りを解除します。吹き飛ばし・場所替え・身代わり直後の対象は、そのターンの移動を行いません。身代わりのHPは元の敵から継承し、自然消滅しません。与ダメージ点は残HPを超えない実ダメージで計算します。

マップは格子（千鳥配置もあり）、ランダム点を平面グラフで結ぶ不整形な回廊、6・7・8ノードの小階層の3系統です。2階以降の配分は格子40%、不整形45%、小階層15%（1階は不整形60%、格子40%）。不整形は24〜30ノードを最小全域木で連結して交差しない辺を追加します。小階層は6・7・8ノードを等確率で選び、6ノードは4種類、7・8ノードはそれぞれ8種類（計20種類）の検証済み配置から選択し、左右反転も行います。14Fまではいずれも通常の敵AIに対して、杖なし・無被弾で到達でき、最短経路よりも遠回りまたは待機が必要な構成です。階段に乗るターンの敵行動も含めて検証しています。敵は最短距離の追跡と、プレイヤーの階段への次の一歩を予測した先回りを組み合わせます。

検証：`node --test engine.test.cjs scores.test.cjs`

階層開始・隣接・討伐時にフレーバーログを表示します。演出用乱数は戦闘・生成の乱数と分離し、継続隣接中の演出は3ターン間隔です。倒れたキャラクターはパンになって小人に運ばれ、オーブンで元に戻る世界観です（演出のみでゲームの復活効果はありません）。

矢印による射線選択は通常移動と共通の方向判定です。押した方向から60度以内の終点を近い順に選び、同方向の再入力で候補を巡回します。該当方向がなければ最も近い方向を選びます。連続待機のログは初回のみ表示し、2回目以降は隣接フレーバーも抑制。移動・攻撃・発射・階段移動や敵の攻撃などが発生した時に合計を1行で出します。方向選択や装備変更だけでは待機集計を確定しません。

小階層を含め、メイジ以外の各敵をメガタウロスにする確率は10Fで1/3、15Fで2/3、20F以降は100%です。10〜20Fは線形に増加し、9Fまでは出現しません（各敵の独立抽選）。紫色のMと枠線で表示しHPは90。受けるダメージは通常と同じ。通常攻撃は40±1〜10（符号と絶対値は独立抽選）、痛恨は16%で80に3回の−3〜+3を加算し再ロールなし。討伐点は300、総討伐数は1体として数えます。レベル進捗はLV10未満で3体分、LV10以降は1体分です。杖は各ノードで20度まで、初期射出方向からは30度まで曲がれます。

杖の準備中、射線の終点ノードまたは候補ボタンにポインタを合わせると、接続先のうち角度制限で除外された未通過ノードを橙色の点線で表示します。表示値は「曲がり角 / 初期射出方向との差」で、20度・30度のどちらを超えたかも説明します。通過済みノードへの逆戻りは候補に含めません。同一終点に複数の射線がある場合、ノード上は選択中の射線（未選択なら先頭候補）、候補ボタン上はその射線を表示します。ホバーやフォーカスは選択・ターン・使用回数を変更しません。

敗北時は既存のゲームオーバー文言を保持し、実在作品からの短い引用（原文・ゲーム独自の日本語訳・著者と作品中の話者・出典リンク）を追加します。5条件と通常用の計6種類。重複時は D→C→B→E→A→通常用の優先順位です。Dは冒険を通じてプレイヤーが初めて受けたメガ痛恨での死亡。Cは致死攻撃直前HPが攻撃者の通常攻撃最大値（通常23／メガ50）を上回り、残り杖回数が1以上ある痛恨死。Bは杖を拾った履歴があり全種残数0の通常攻撃死。Eは通常移動直後、その敵が敵行動開始位置から動かずに攻撃して死亡した場合（剣攻撃・待機・場所替えは除く）。Aは1〜2Fでの死亡。引用は条件別の候補からランダムに選び、同じ敗北画面の再描画では変わりません。

セリフ編集は dialogue.js、敗北名言の編集は defeat-quotes.js。詳しい一覧・追加方法は「セリフ編集ガイド.txt」を参照してください。

15F以降は、小階層を含む毎階にミノタウロスメイジが1体追加されます。緑色のMと右上の小さなMで表示。HP45・近接攻撃は通常種と同じ。4種類から等確率で杖を所持し、混乱は1〜3回、ほかは2〜5回です。射線上の最初の相手に魔法を使い、残数0なら通常の追跡・攻撃に戻ります。金縛り中のプレイヤーは行動を試みると敵のターンだけが進み、被ダメージで解除。混乱は5ターン、移動・剣攻撃の方向がランダムになりますが、杖の射撃は正確です。吹き飛ばしの壁衝突は10ダメージ、敵との衝突は双方10ダメージ。メイジによる敵へのダメージ・討伐はプレイヤーの得点に加算しません。倒れると残り回数のある杖を落とし、混乱の杖は拾うと身代わりの回数になります。既存アイテムと同じ場所に落ちた場合も両方拾えます。メガタウロスは右上に小さな2を表示し、どの敵も金縛り中は青系になります。

デバッグ画面の「開始マップ」で6・7・8ノードの各配置（6ノードは1〜4、7・8ノードは1〜8）を選択でき、「小階層の向き」で左右反転も指定できます。指定は開始階だけに適用され、降りた先は通常のランダム生成です。デバッグ中はマップ見出しに配置番号・反転の有無を表示します。15F以降はメイジが追加されるため、無戦闘ルートの確認には14F以下を選んでください。

7・8ノードの全配置1〜8は、三つ又・袋小路・複数の迂回路を含む分岐型の平面グラフです。各サイズで接続構造が異なる8種類を用意しています。小階層の出現間隔に制限はなく、2F以降は毎階15%で抽選します。連続出現もあります。

小階層をノーダメージで突破すると、階段を降りた時にLV +1のボーナスと専用ログが出ます。最大HP・現在HPは各+10、剣の基本ダメージは到達LVが偶数なら+1・奇数なら+2。LV5・LV15の乱数拡大も適用し、討伐進捗は新しいレベルで0から数え直します。入場時のHPが減っていても、その階で被ダメージがなければ対象です。通常攻撃・痛恨・魔法衝突のいずれかでダメージを受けたら、回復しても対象外。戦闘や杖の使用自体は失格になりません。15F以降やデバッグ探索にも適用します。

小階層の入場時にはノーダメージ突破でLV +1になる案内を表示します。剣の再ロールで実際に複数回攻撃した場合、ダメージログに「n回ヒット！」を追加します。初撃で倒した場合は1回扱いです。

効果音は ../material/se/ のWAVファイルを参照します。ax_attack：敵の近接攻撃による被ダメージ、bell：小階層到着、gameover：敗北、magic_cast：プレイヤー／メイジの杖使用、money：ゴールド／杖拾得、step：階段移動、sword_attack：剣攻撃。音量45%、画面上部のボタンでON／OFFを切り替えられます。ブラウザーの自動再生制限により、操作前の再生が拒否される場合があります。ゲーム処理は音声の再生可否に影響されません。公開・移動時は material/se も相対位置を保って配置してください。

プレイヤーの金縛りが被ダメージで解除された場合、次の有効な1行動を行うまで再金縛りを防ぎます。方向選択・装備変更・無効操作では保護を消費しません。移動・剣攻撃・射撃・待機・階段移動で保護が終了し、その後の敵ターンでは再び金縛りになる場合があります。他の攻撃によるダメージは防ぎません。

敗北画面の「最後の盤面を見る」で結果表示を隠し、盤面とログを確認できます。「結果画面に戻る」で再表示します。閲覧中も探索は終了した状態で、ターンは進みません。

BGM：初回に曲順を一度シャッフルし、同じ順列で巡回します。1〜2F、3〜4F……の2階層ごとに次の曲へ移り、その間に曲が終わったらループします。デバッグ開始時は指定階から2階層単位です。敗北時はBGM停止後にゲームオーバーSEを再生し、盤面閲覧や音量操作ではBGMを再開しません。新しい探索・再挑戦・デバッグで開始すると順列を1つ進めます。ページを再読み込みすると新しい順列になります。初回はクリックまたはキー操作で音楽が始まります。BGM・SEの音量は別々に調整でき、ブラウザーに保存されます。

音源追加の自動反映：start-game.cmd をダブルクリックしてください（Node.jsが必要）。localhostのゲームが開き、material/music の直下にあるmp3・wav・ogg・m4a・aac・flacを30秒ごとに確認します。新しい曲は既存の順列を変えず末尾へ追加し、次にその位置を再生する時から流れます。終了は起動したコンソールでCtrl+C。サーバーは127.0.0.1のみで待ち受けます。ポートを変更する場合は環境変数 ARIADNE_PORT を指定して node start-server.cjs --open を実行してください。

index.html の直接起動も引き続き可能ですが、ブラウザーはローカルフォルダーを自動列挙できないため、music-library.js に収録した20曲を使用します。追加曲の自動反映はローカルサーバー起動時に利用できます。ローカルサーバーとファイル直接起動では保存元URLが異なるため、ランキング・音量設定はそれぞれ別の記録になります。元の記録は元のURLで引き続き閲覧できます。

25階ごとの分岐と二周目以降：
- 15〜24F、40〜49F、65〜74F、80〜99F、それ以降は各分岐の直前10階層（115〜124Fなど）のランダムな1階に、謎の紋章（"）を必ず配置します。拾うかどうかは任意。所持中の敵からの直接攻撃（通常・痛恨）は1.2倍、端数切り捨て。魔法の衝突ダメージは変えません。デバッグ開始時は所持済みです。
- 25F、50F、75Fなど25階ごとの分岐は生成指定より優先される固定Y字マップで、敵・拾得物は出現しません。右端に乗って > を押すと帰還し、300,000点を一度だけ加算して終了します。白い画面のエンディングに指定クレジットを表示し、スコア・結果・ランキングに☆を付けます。クリアでもランキング登録可能（デバッグは除外）。敗北音は鳴らさずBGMを停止します。
- 各分岐の左端で > を押すと紋章を消費し、次の階へ進みます。紋章がなければ入れず、右の出口へ引き返せます。51F以降も後半の敵構成・ゴールド20倍を維持し、豪傑は現在階層・レベルに応じて強くなります。
- 26〜49Fは豪傑（青のM³）を26F20%、27F40%、28F60%、29F80%、30F以降100%でメガタウロスに代えて生成。加算値は floor(10+(LV+階層)/1.4142)。HPは生成時に90へ加算し固定、通常・痛恨ダメージは攻撃時のLV・階層で算出した値をメガのダメージへ加算します。経験値はメガ2体分（LV10未満は通常種6体分、LV10以降はメガ2体分）です。身代わり化しても同じです。討伐点300・総討伐数1体・レベルアップ時の進捗リセットは従来どおりです。
- メイジは通常階2体、小階層1体。不死（紫のMᵁ）は小階層を含む毎階1体。HPは無限、剣と衝突のダメージは0（得点なし）。4種類の杖は全て有効で、身代わりになっても不死のままです。不死の直接攻撃は通常ミノタウロスと同じです。小階層では遠い空きノードがなければ隣接ノードも敵配置候補にします。
- 40〜49Fでは階層内の30ターンごとに冥界（黒に白縁のMᴰ）を1体追加。出現直後は動かず次ターンから追跡します。金縛りで行動できないターンも経過に含みます。空きがない場合は空き次第出現。冥界のHPは未指定のため通常種と同じ45を採用。4種類の杖が有効です。プレイヤーが接触するか、冥界がプレイヤーに攻撃しようとすると、ダメージなしで次の階へ転送します。移動得点1,000点は入りますが、小階層のノーダメージ突破ボーナスは付与しません。階層内ターン数と冥界出現数は移動時にリセット。
- 二周目のゴールドは40〜4,000点（通常の20倍）。分岐には出現しません。

追加ルート検証：node --test engine.test.cjs scores.test.cjs music.test.cjs second-loop.test.cjs

追加調整：Y字路の左右端は、乗るだけでは進行せず、>キーまたは「この先へ進む >」ボタンで確定します。紋章がなくても扉の上には乗れ、引き返せます。冥界が身代わりを攻撃しようとすると、身代わりの残HPや不死属性にかかわらず両者が消滅し、討伐報酬・ドロップは発生しません。

35F以降の通常階では、迷宮殺しと量子メガタウロスを共通の追加枠から迷宮殺し30%・量子30%・なし40%で、最大1体を追加します（小階層・分岐には追加しません）。
- 迷宮殺し：茶色のMᴮ。HP45・通常種と同じ攻撃。現在位置から320以内の未接続ノードを選び、既存辺と交差せず他ノードの上も通らない道を4行動かけて開きます。選択したターンを1ターン目とし、4ターン目の敵行動で完成。工事中は移動・攻撃をせず、予定線は点線で表示します。金縛り中は進捗停止。吹き飛ばし・場所替えで位置が変わった場合や他の工事で候補が無効になった場合は、次の行動で工事を中断します。通路はその階限りです。
- 量子メガタウロス：ピンク色・白縁のMᑫ。初期HP90・メガと同じ攻撃。行動可能時に25%で能力を試み、使用後4行動は通常行動です。分裂は現在HP・最大HP・攻撃倍率を二分（HPの端数は親側へ）し、分身と自分を空きノードへ転移。HP12未満では分裂しません。同系統の実体は最大4体、攻撃力0・HP1でその場に留まる幻影は最大2体。幻影はテセウスの身代わり@とは別物で、敵の追跡対象を変えません。幻影は剣・衝突で消え、得点・討伐経験値を出しません。4種類の杖は実体にも幻影にも有効です。

通常階の初期敵数：10〜14Fは通常・メガ6体、15〜24Fはそれにメイジ1体で7体、26〜34Fはメガ・豪傑6体＋メイジ2体＋不死1体で9体、35〜49Fはこの9体に迷宮殺しか量子を0〜1体追加し9〜10体です。配置候補不足の場合は減ることがあります。小階層の敵数・量子の分裂・冥界の途中出現は従来どおりです。

敵情報：敵にポインタを合わせるかTabでフォーカスすると、種類・HP・対プレイヤーダメージ範囲・特殊能力・状態・討伐報酬を表示します。ダメージ範囲は紋章や分裂の倍率を反映します。情報を見るだけではターンは進みません。

エンディングは、帰還メッセージとクリアボーナスの案内 →「進む → スタッフロール」→ クレジットと結果操作ボタン、の順に表示します。進むボタンで得点が再加算されることはなく、最後の盤面から戻ってもスタッフロールの段階を保ちます。

タイトル・セーブ・サウンドテスト：
- 起動時は material/img/ariadne_title.png を表示し、「初めから」「続きから」「サウンドテスト」を選べます。タイトル画像の制作：ChatGPT をスタッフロールへ追加しました。
- 探索は各操作後にブラウザーへ自動保存します。「タイトルへ」で一時中断し、「続きから → ブラウザデータから再開」で戻れます。タイトルでは時間は進まず、探索音は停止します。初めからを選ぶ際、セーブがある場合は上書き確認が出ます。敗北・クリアすると途中セーブを消去します。
- 「JSON保存」で途中の探索を書き出し、「続きから → JSONファイルを読み込む」で別ブラウザーでも復元できます。読み込めるのは現バージョンで書き出した未終了の探索です。デバッグ状態も維持します。不死のHP、工事進捗、状態異常、拾得物、探索済みノード、ログを復元します。BGMの順列・選択曲・切り替え階層も可能な限り復元します（曲の再生位置は先頭から、未配置の音源は除外）。ランキングと音量設定はセーブJSONとは別です。
- ブラウザー保存に失敗すると画面上に表示します。その場合はJSON保存をご利用ください。file:直接起動とlocalhost起動は別の保存領域です。
- サウンドテストでBGM／SEを選び、再生・停止・ループ・音量調整ができます。試聴の音量はゲームの音量と独立し、BGMの巡回位置も進めません。音源追加の検出は従来どおりサーバー起動時です。追加曲を試聴する場合は、曲／効果音の種類を切り替えるかテスト画面を開き直してください。
- コメントは sound-comments.js のみで編集します。プレイヤー画面は閲覧専用です。音源のファイル名をキーに、例："dungeon_synth1.mp3": "この曲についてのコメント" と記載してください。以前ブラウザーで保存したコメントは使用しません。

全テスト：node --test engine.test.cjs scores.test.cjs music.test.cjs second-loop.test.cjs saves.test.cjs title.test.cjs
