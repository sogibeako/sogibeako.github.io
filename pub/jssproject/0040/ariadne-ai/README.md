# Ariadne AI Observatory

`index.html` をブラウザーで開くと、AIのプレイを観戦できます。ビルド・インストールは不要です。隣の `ariadne-graph-escape` ディレクトリを同じ配置で残してください。

- 「1手進める」「自動再生／一時停止」、速度変更で観戦します。
- 先読みは1～3手。設定変更は「新しい冒険」の開始前に行います。深い先読みほど時間がかかります。
- シードを同じにすると、同じ設定・同じゲームルールで再現できます。
- 分かれ道では帰還、または紋章があれば続行を選べます。
- 連続試行はシードを1ずつ増やして実行。最大1,500ターンで打ち切り、敗北と区別して記録します。一時停止・中止ができます。
- 成績は本編とは別キーでブラウザーに最大500件保存。直近100件を表示し、JSONには保存中の全件を書き出します。ブラウザーの保存制限がある場合はJSONを使ってください。
- このアプリは無音です。本編のセーブ・ランキングを変更しません。

## AIの仕組みと限界

これは自動学習するAIではなく、固定の評価式を使った先読みAIです。実際の `../ariadne-graph-escape/engine.js` を参照して盤面を複製し、移動・待機・剣・敵に当たる射線の4種類の杖を試算します。各初手に3通りの独立した乱数を与え、さらに各先読み段階で最も評価の高い行動を選びます。全手順を網羅する探索ではありません。

生存・HP・階層突破・出口への距離・得点・杖の消費・同じ場所への滞在を評価します。平均70%＋最悪結果30%で初手を比較します。予測HPは先読み終了時の平均で、勝率や確定値ではありません。表示中の敗北数も3試算中の回数です。

現在の盤面にある敵の内部状態（HP・杖・状態異常など）を参照します。人間と完全に同じ情報制限ではありません。実戦の乱数は読まず、未来の階層に進んだ試算はそこで打ち切ります。迷宮生成や戦闘ルールを本編と共有するため、本編の更新も反映されます。

弱点は、浅い先読み、少ない乱数試算、固定の評価式です。安全な道の保証や完全攻略はありません。成績を比較するときは、同じシード群・ターン上限・分岐方針を使ってください。ブラウザーでは別タブにするとタイマーが遅くなることがあります。

## ファイル

- `ai.js`：行動候補・盤面複製・評価・先読み
- `app.js` / `index.html` / `style.css`：観戦・説明・連続試行・成績
- `benchmark.cjs`：Node.jsで画面なしの連続実行
- `ai.test.cjs`：状態の分離、乱数、合法手、危険回避のテスト

プロジェクトの親ディレクトリから：

```sh
node --test ariadne-ai/*.test.cjs
node ariadne-ai/benchmark.cjs 3 2 300 42
```

引数は冒険数、先読み深さ、ターン上限、最初のシード。1行につき1冒険のJSONを標準出力に返します。

## 初期評価

## 戦闘・出口の閉塞への対応（v2）

単なる辺数の最短距離に代えて、敵HPと剣の攻撃力から通路を開く手間を加えた経路を評価します。金縛り中でも敵がノードを占有している点は変わりません。敵HPを削った進捗も加点し、倒すまで距離が縮まらない戦闘を選びやすくしました。不死は有限HPの討伐進捗として数えず、迂回・杖を比較します。低HPでは試算中の敗北への大きな減点を維持します。

出口上の凍結した通常敵を倒して降りる再現テストを1〜3手先読みで追加しました。低HP時の自殺的攻撃の回避、不死の出口占有に対する場所替えも含め、自動テストは11件です。

combat-baseline.json はv2の比較結果（同じシード42〜51、2手、300ターン上限）。平均2741点・最高4F・帰還0回・ターン上限0回でした。v1の平均1666点から改善していますが、10冒険の限定的な比較です。一般的な攻略成功や全状況での停滞解消を保証するものではありません。旧baseline.jsonは比較用に残しています。新しい観戦成績にはagentバージョンも保存します。

## 方針切り替えと痛恨予測（v3）

方針は観戦画面のTHINKING欄に表示します。毎ターン、危険を先に確認して更新します。

- 回復：HP65%未満で、活動中の敵が2辺以内におらず、杖を残したメイジもいなければ開始。90%まで維持します。回復中は待機・同じ場所への滞在の減点を軽くします。敵が近づけば切り替えます。この安全判定は保守的な近似で、完全な安全保証ではありません。
- 戦闘：隣接した敵や出口をふさぐ敵を対象に、同じ階・2辺以内にいる限り対象を保持し、対象のHPを削る進捗を加点します。危険が増したら退避を優先します。
- 脱出／退避：出口・分かれ道へ向かい、隣接敵の通常最大ダメージの合計に、1体分を最大痛恨へ置き換えた値を見て退避方針に切り替えます。最後の行動選択は先読み評価が行うため、止めを刺して安全を確保することもあります。

通常の3試算とは別に、試算中の最初の対プレイヤー直接攻撃を最大痛恨に置き換える危険シナリオを1つ加えます。その後の攻撃は元の乱数ルールに従います。複数敵の攻撃もエンジンどおりに進行します。シナリオは盤面のコピーだけに適用し、本編ルール・実戦の乱数を変更しません。通常試算の敗北数と、危険シナリオの残HP／敗北を分けて表示します。

評価は通常試算（平均80%＋最悪20%）を84%、危険シナリオを16%で混合します。これは保守的な判断のための重みで、厳密な死亡確率や確率期待値ではありません。連続する複数の痛恨を網羅するものでもありません。従来の固定評価式を改良したもので、機械学習はまだ行っていません。

自動テスト16件が通過。回復方針の継続と終了、敵接近時の切り替え、階層変更による対象解除、痛恨の1回置換とコピー継承、複数敵の危険量、通常試算と痛恨試算の表示データを追加検証しています。出口の金縛りのテストでは、敵を倒した後に安全に回復する時間も許容しています。

比較結果は tactics-baseline.json に保存しました。同じシード42〜51・2手先読み・300ターン上限で、平均得点は2741→4368、最高到達階は4→8、帰還は0→0でした。10シードの限定的な比較であり、25階クリアはまだ確認できていません。実ブラウザーの見た目は未確認です。

## 戦闘練習場・結果からの学習

training.html を開いてください。観測室の右上にもリンクがあります。本編のエンジンを共有し、ゲームルールとランキングは変更していません。従来の冒険AIと、この実験用学習モデルは別物です。冒険AIには学習モデルを自動適用していません。

### 操作

1. 学習シードと世代数を指定して「学習を開始」。初期値は8世代です。
2. 「停止」は完了した世代までのモデルを保持します。計算は8ターンごとに画面操作へ制御を戻します。
3. 学習前・後の評価用課題の結果を比較します。
4. 「課題を作る」「1手進める」「観戦」で現在のモデルを試せます。未見の課題シードでも確認してください。
5. モデルはブラウザーの ariadne-trained-model-v1 に保存。JSON書き出し・読み込みもできます。「初期モデルに戻す」で初期状態を保存し直します。

今回実行した8世代のモデルは training-result-model.json、学習経過は training-result.json です。練習場内のリンクからモデルを保存し、「モデル読込」で読み込めます。最初から自動で学習済みモデルを使う仕様ではありません。

### 学習方法

6〜8ノードのランダムな連結平面グラフ（格子の全域木に一部の辺を追加）、敵1〜3体、LV1〜5、最大HPの約50〜100%、ランダムな杖配布で課題を生成します。一部はメイジです。各戦闘は全員消滅・プレイヤー敗北・80ターンで終了し、階段を使う行動は対象外です。

評価式の11個の重みを変異させ、4候補×学習用8課題の戦闘結果を比較して、最も成績がよい候補を採用します。元モデルより悪い候補は採用しません。評価用8課題は候補選択に使いません。これは線形方策の進化的な重み探索であり、ニューラルネットやTD学習ではありません。

行動選択では、各合法手を独立した2つの乱数で1手だけ試算し、HP・討伐数・敵の残HP・杖残量・凍結数・身代わり数・隣接活動敵・自由な隣接ノード・敵距離・滞在・経過ターンの線形評価で選びます。敗北と全員討伐には固定の終端評価もあります。重みを採用するかどうかは、1手の評価ではなく最大80ターンの戦闘全体の結果で決めます。

戦闘結果の報酬は、討伐数×200＋全員消滅時300＋生存100（敗北は−300）＋残HP×0.6−ターン数×0.5−杖の純消費回数×3です。回復した回数や金縛りした回数自体を報酬にしていません。凍結や身代わりは特徴量ですが、「金縛り→攻撃」などの手順や配置は固定していません。

### 検証結果と限界

初回の8世代で、選抜に使わない8課題の全員討伐は3/8→7/8でした。その後、別の64課題（シード2000123〜2000186、候補選抜には不使用）で確認した結果は46/64→50/64。平均報酬は596.37→595.43で、わずかに下がりました。全員討伐率の改善が、全指標での改善を意味するわけではありません。詳細は training-audit.json にあります。

同じ学習シードでは同じ課題群を繰り返すため、学習課題への過適合が起こり得ます。また、特徴量が限られ、行動選択自体は1手先読みのため、身代わりの閉じ込めのような複雑な連続手筋を獲得したとはまだ確認していません。25階攻略の学習・達成もまだです。

既存機能を含む自動テスト26件を実行しました。課題の接続・多様性・配置、実戦状態の非変更、モデル検証、学習と評価の分離、停止、再現性、UIの学習・保存・不正JSON読込を検証しています。画面テストはDOM代替による動作確認で、実ブラウザーの表示は未確認です。

コマンドで実行する場合（プロジェクト親ディレクトリから）：

    node ariadne-ai/train.cjs 8 123
    node --test ariadne-ai/*.test.cjs

出力ファイルを指定する場合は3番目の引数で指定できます。指定先のレポートと、その隣の -model.json を更新します。

## 学習モデルを冒険で試す（実験用）

観測室 index.html に「AI：従来AI／学習モデル併用（実験）」を追加しました。標準は従来AIです。

1. 新しい冒険を作ります。
2. 練習場でブラウザーに保存したモデルは自動で読み込みます。表示されない場合や別のモデルを試す場合は「モデルJSON」で読み込みます。付属の training-result-model.json も利用できます。
3. 「学習モデル併用」を選んでから、1手送りまたは自動再生を開始します。
4. 冒険開始時のモデルをコピーして固定し、終了時の成績にも重みを保存します。途中でAIの設定を切り替えることはできません。
5. 結果表にはAIの種類を表示し、平均点も従来／学習併用で分けます。この画面の平均はシードや条件をそろえた比較ではないため、公平な比較には下記のコマンドを使ってください。

学習モデルは従来の先読みと痛恨試算を置き換えません。試算局面の特徴量と現在局面の差を学習した重みで採点し、8倍した補助値を±120に制限して加えます。敗北・帰還・次階への移動が成立した局面には補助値を加えません。通常の単独学習モデルと、この併用モデルは動作が異なります。

    node ariadne-ai/compare.cjs ariadne-ai/training-result-model.json 10 42

両方式を同じ開始シード群・2手先読み・各300ターン上限で実行し、adventure-comparison.json に結果と使用モデルを保存します。行動が異なると消費する乱数も異なるため、途中から生成される階層まで同一とは限りません。

今回の10シード（42〜51）の結果：従来は平均4368点・最高8F、学習併用は平均3593点・最高7F。帰還は両方式とも0回、学習併用は1回ターン上限に達しました。小課題での学習改善は、この冒険の成績改善にはつながっていません。自動で学習併用へ切り替えず、比較・観察用の実験モードとして残しています。次の課題は、長期的な育成や大きなマップを含む学習分布への拡張です。

自動テストは30件です。モデル読込、冒険開始時のモデル固定、未読込時の開始防止、学習補助値の非破壊性、帰還判断の維持を追加で確認しています。実ブラウザーでの見た目は未確認です。

## 大マップ・連続攻略と盤面反復（追加）

練習場のコース選択から以下を選べます。観戦も同じコースで「課題を作る」を押して開始します。

- 小規模戦闘：従来の6〜8ノード、80ターン上限。
- 大マップ戦闘：本編の格子／不整形マップを使う4F。LV4・HP130・杖4/4/3/1で開始し、全員討伐を160ターン以内に狙います。開始条件をそろえた練習用設定です。
- 1〜5階の育成・攻略：本編どおりLV1・HP100・杖なしで1Fから開始し、240ターン以内の6F到着で成功。HP、杖、経験値、レベルを階層間で引き継ぎます。従来AI＋学習モデルの実際の併用方策（1手・通常1試算＋痛恨試算）で学習します。

連続攻略の結果報酬は、降りた階数×300＋レベル上昇×150＋討伐数×120＋生存100（敗北−400）＋残HP×0.6−ターン数×0.5です。階層と育成の長期利益を候補選抜に使います。コースを変えても同じ重みを引き継いで追加学習できます。学習用と評価用のシードは分離しています。

### HPを回復しない盤面反復

プレイヤー位置・階層・敵の位置/HP/状態・杖・通路・アイテム・踏破状態などが同じ盤面への再訪を数えます。連続待機だけでなく往復も対象です。時刻、ログ、経過ターン、プレイヤーHPそのものは盤面キーに含めません。

最初の3回は0点、4回目から−2、−4…と少しずつ減点し、最大−20に制限します。プレイヤーHPが前回の実行状態より増えた時点、または階層が変わった時点で履歴をリセットします。同じターンに判断を何度要求しても回数は増えません。先読みは実戦の履歴を読むだけで、候補の試算によって回数が水増しされることはありません。

従来のノード滞在回数による減点は撤去しました。冒険AIと練習場に共通適用します。学習特徴量の10番目も「滞在回数」から「停滞反復（減点/20）」へ変更しています。旧モデルJSONは読み込めますが、この重みの意味が変わるため、旧バージョンと同じ行動の再現は保証しません。今回の実験モデルは新しい定義で追加学習したものです。

### 実行記録

大マップを1世代追加学習（シード654、8課題）したモデルは large-training-model.json。評価用8課題の全員討伐は6→7件でした。連続攻略を2世代追加学習（シード321、8課題）したモデルは campaign-training-model.json。評価用8課題の6F到着は学習前後とも0件で、まだ育成・長期攻略を十分に学べていません。どちらも元の小課題8世代モデルから別々に開始しました。小さな検証結果なので一般的な改善を保証しません。練習場に各モデルの保存リンクがあります。

CLIの追加引数は、出力先の後にコース名と開始モデルです。

    node ariadne-ai/train.cjs 2 321 ariadne-ai/campaign-training.json campaign ariadne-ai/training-result-model.json
    node ariadne-ai/train.cjs 1 654 ariadne-ai/large-training.json large ariadne-ai/training-result-model.json

全37件の自動テストが通過。反復の4回目しきい値、HP回復リセット、攻撃・移動による盤面区別、同一ターンの二重計上防止、コース生成・完了条件・上限、連続攻略観戦の旧80ターン制限解消を確認しました。実ブラウザーの見た目は未確認です。

## 11項目を引き継ぐ配置学習と複数候補の先読み（モデルv2）

旧v1モデルの11個の重みと世代数はそのまま引き継ぎ、配置の7項目を末尾に重み0で追加します。重みの並びを入れ替えたり、旧重みを初期値に戻したりしません。追加学習では旧11項目も含む全18項目を調整します。旧重みを固定する方式ではありません。既存の反復特徴量の意味は前回の実装から変更していません。

新しい項目は、敵のノードを通れないものとして調べた移動可能領域、そこへ侵入可能な活動敵、最短の接近余裕、出口までの自由経路、凍結による活動敵の遮断、凍結による出口閉塞、身代わりの自由な隣接ノードの少なさです。いずれも配置の近似指標で、メイジの射撃や全ての将来移動を保証する安全判定ではありません。杖を使う順番は指定していません。

v2モデルは特徴名と18個の重みを保存します。v1の読み込み時に自動拡張し、v2では特徴名と順序も検証します。古いアプリへ新しいモデルを読み戻すことはできません。現在のアプリは両形式を読み込めます。
