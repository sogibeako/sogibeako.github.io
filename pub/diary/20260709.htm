数学：ファイバー積のこと

ファイバー積は写像f,gと同値関係と空間X,Y,Zから導かれる積で、空間Zが一点の時、単なる積と一致するらしい。$$ X\overset{f}\longrightarrow Z\overset{g}\longleftarrow Y$$がある時、$$X \times_Z Y = \lbrace(x,y)\in X \times Y \mid f(x) = g(y) \rbrace$$を作る。例えば数も入れられる。有限集合として$$X=\{1,2,3\},~~Y=\{4,5,6,7\},~~Z=\{0,1\}$$を考えて、各写像を$$f(x)=x\bmod 2,~~~~g(y)=y\bmod2$$とすると、ファイバー積は$$X\times_Z Y= \{(x,y)\mid x \equiv y \bmod 2\}$$となる。つまり、xとyが法を2として合同となる組み合わせを選出することになるので、$$(1,5),~(1,7)~,(2,4)~,(2,6)~,(3,5)~,(3,7)$$が残る。

一般に、有限集合のファイバー積の要素数は$$|X \times_Z Y| = \sum_{z\in Z}|f^{-1}(z)||g^{-1}(z)|.$$となるらしい。先程の例で検算すると、$$f^{-1}(0) = \{2\},~~f^{-1}(1)=\{1,3\}$$よって \(f^{-1}\) については、$$|f^{-1}(0)|=1,~~|f^{-1}(1)|=2$$となり一方、$$g^{-1}(0)=\{4,6\},~~g^{-1}(1)=\{5,7\}$$よって \(g^{-1}\) については、$$|g^{-1}(0)|=2,~~|g^{-1}(1)|=2$$となる。（注：ちゃんと \(Z\) の逆像から考えること。最初、ファイバー積後の空間から考えてよくわからなくなった）
偶数側 \(z=0\) では、\(1\times2 = 2\)、すなわち\((2,4),~(2,6)\) が出来る。奇数側 \(z=1\) では、\(2\times2 = 4\)、すなわち\((1,5),~(1,7),~(3,5),~(3,7)\) が出来る。したがって、計6個。

もちろん写像は自由に変えることが出来て、例えば$$\mathbb Z \xrightarrow{\,a\mapsto a^2\bmod n\,} \mathbb Z/n\mathbb Z \xleftarrow{\,b\mapsto b^3\bmod n\,} \mathbb Z $$とすると、$$\mathbb Z\times_{\mathbb Z/n\mathbb Z}\mathbb Z = \{(a,b):a^2\equiv b^3\pmod n\}. $$となり、合同方程式の解集合となる。

もしも \(Z\) が一点なら、条件 \(f(x) = g(y)\) は自動的なので、通常の掛け算になる。（つまり終対象 \(1\) の上の引き戻しは通常の直積になる……）

もうちょっと細かくヴェブレン階層についての実験と覚書

通常のヴェブレン階層については省きつつ、超現実数においては、順序数 \(\omega\) に対応するものとして、$$\omega = \lbrace0,1,2,\cdots\mid\rbrace$$というものがあり、そこからデクリメントをすると、$$\omega-1 = \lbrace 0, 1, 2, \cdots \mid \omega\rbrace$$$$\omega-2 = \lbrace 0, 1, 2, \cdots \mid \omega, \omega-1\rbrace$$という風になっていく。左手と右手のせめぎ合いになっていて、左手はとにかくどこまで下から抑えられるか、右手はとにかくどこまで上から抑えられるか、それで二分木を形成するという感覚が近い。このままどんどこ減らすと、$$\dfrac{\omega}{2}=\lbrace0,1,2,\cdots\mid\omega,\omega-1,\omega-2,\cdots\rbrace$$$$\dfrac{\omega}{4}=\lbrace0,1,2,\cdots\mid\omega,\omega-1,\omega-2,\cdots,\dfrac{\omega}{2},\dfrac{\omega}{2}-1,\dfrac{\omega}{2}-2,\cdots\rbrace\rbrace$$$$\omega^{\frac{1}{2}} = \lbrace0,1,2,\cdots\mid\omega,\dfrac{\omega}{2},\dfrac{\omega}{4},\cdots\rbrace$$という風になっていくというのがいわゆるConwayのω-mapというもので、ここでヴェブレン階層の0階が$$\omega^\alpha = \Phi(0, \alpha)$$というものだったことを思い出すと、$$\omega^{\frac{1}{2}} = \Phi(0,1/2)$$と考えることが出来るよね、つまり、「超現実数における各変数は、いずれも超現実数それ自体を再演するのではないか」という仮定から入った。シーケンスっぽく書くと$$\omega^{+-} = \Phi(0,+-)$$みたいなこと、そして$$\Phi(1,0) = \Phi(0, \Phi(1,0)) $$$$\Phi(2,0) = \Phi(1, \Phi(2,0))$$なのだから$$\Phi(1/2,0) = \Phi(1, -\Phi(2,0))$$なのではないか、みたいなこと……。

その着想をChatGPTに依頼してLeanを実験してもらい、今のところ第一変数にω日目の数（任意の正の有理数）を入れても破綻が起きない『らしい』、というところまでは話をしてきた。

\(\Phi(1/3, 1)\) は「あることはわかった、だがこの記号の意味がオヌシにわかるかぁ～？（by ChatGPT）」という感じになってきた（地力不足を感じて悲しい）。どうも、$$\Phi(1/3, 1) = \Phi(1, 何か_1) = \Phi(1, -\Phi(2, 何か_2)) = \cdots$$という感じで、各 \(\cdots\) 部分で座標変換しながら伸びてくことになるようなのだが、それの同定がなかなか難しいみたい。実際、1→何か1の部分で、正負の時点で入れ替わってるし……。あと、$$\Phi(1,\Phi(3,0)) = \Phi(2, \Phi(3,0))$$なので、そもそも \(\neg\forall \in \text{No}~~[\Phi(1, x) = \Phi(2, x)]\) ではある。要するに不動点で各階層の像がぶつかるので、第一変数を上げれば単純に「値域全体が上へ移動する」と考えるのはちょっと違うんですよね。

MoSのゆらぎ

このように、L:sの比率を変更していくことを考えるのは、色々な音階同士の繋がりを考える上でも有効だ。純正律を考える場合は大全音、小全音といったように音程が複雑化することもあり、自分は次のような記法を提案する。$$(K~\geq~)~L~\geq~M~\geq~N~\geq~\cdots~\geq~r~\geq~s$$このように書けば、例えば12平均律のハーモニックマイナーのような「増二度」を有する音階も表記しやすい。すなわち、LsLLsKs、すなわち 1K3L2s となる。

これは面白い。
もしも K=L とすれば LsLLsLs 、すなわち 4L3s（11EDOなどを代表とし、Orgone, Hyperkleismic, Sixix,などで知られるシリーズ）へと接続し、またもしも L=s とすれば、Kssssss → Lssssss、すなわち 1L6s（8EDO, 15EDOなどを代表とし、NegriやPorcupineなどで知られるシリーズ）へと接続する。これは実地に作曲する場合においても役に立つ考察だと言えると思う。つまり、12EDOのMODMOSの一種と言えるハーモニックマイナーと、他のMoSとの関係が示唆されることになる。

こうして見ていくと、「要するに与えられた7音（一般にはn音）をオクターブ内でそれぞれどうずらすか」の話になってきそうである。

また、5L2sの反対側には2L5sがいる。もう、Lとかsと言わずにここでは一旦抽象化してしまって、5a2bと呼ぶことにすると、

…
   a:b = 3:1       // 17edo
      a:b = 5:2    // 29edo
   a:b = 2:1       // 12edo
      a:b = 3:2    // 19edo
a:b = 1:1          // 均衡点。7edo
      a:b = 2:3    // 16edo
   a:b = 1:2       // 9edo
      a:b = 2:5    // 20edo
   a:b = 1:3       // 11edo
…
a:b = 0:1          // 極限。2edo

という系列を見ることが出来る。

Max/MSPやMTSなどを使えば、「楽曲中で連続的にピッチが変わる楽器」などを考えることも出来るだろう。

となると、MoS、あるいは音階とは、「曲線的に変化していく7音の音高をある時刻tで切断した面」と考えることが出来る。 あるいは、もう一つ別次元の「語」として、ある音高軌跡同士が交差してしまうことを考えることも出来るかもしれない。 これは組み紐群のような運動を為し、また音楽としてはクセナキスのMetastasisのような図形楽譜との関係を示唆することが出来るだろう。 これは連続的変化に限る必要はなく、例えば組み紐の一本一本をセリーと見做すなどして、音列の演奏順序が時間によって置換していくといった拡張も可能かもしれない。

また、複数の音高軌跡が一点で一致している場合、その点から時間の一方向だけを見れば、これを分岐と捉えることが出来る。 実際、5EDOから5Lnsによって7音（や任意の6音以上）を展開する際に起きる現象は、それと同等だと見做せると思う。 例えば、Diatonic 5L2sからAntiDiatonic（Mavila）2L5sへの運動は、5EDO→7EDO→2EDOという、分岐と収束の運動として捉えられる。 これもまたクセナキスのMetastasisを示唆するかもしれない。

WSLのデバイスファイルなどを観光する

set -o noclobber

を先に適用して、既存ファイルへうっかり > で上書きしないようにする。

観光中は、

  • sudo を使わない
  • rm を使わない
  • /dev 以下へ書き込まない
  • /sys 以下へ書き込まない
    ことを徹底する。

よく聞く /dev/null をはじめとしたシリーズを見てみる。

🐈@nyankopad:~$ cd test
🐈@nyankopad:~/test$ ls -l /dev/null
crw-rw-rw- 1 root root 1, 3 Jul 17 20:21 /dev/null
🐈@nyankopad:~/test$ ls -l /dev/full
crw-rw-rw- 1 root root 1, 7 Jul 17 20:21 /dev/full
🐈@nyankopad:~/test$ ls -l /dev/zero
crw-rw-rw- 1 root root 1, 5 Jul 17 20:21 /dev/zero

これらは絶対パス /dev/... の中にある、というイメージ。
crw-rw-rw- の先頭の c は「キャラクタデバイス」を意味する。

od：octal dumpの略。もともとはファイルやバイト列を8進数で表示する道具だったが、今は16進数、10進数、文字などでも表示できるらしい。

-An：-A n の短縮された書き方。

  • -A：各行の先頭に表示するアドレス形式を指定
  • n：none。つまり、アドレス欄を表示しないという意味。
