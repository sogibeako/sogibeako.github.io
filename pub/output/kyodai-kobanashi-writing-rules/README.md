# 『兄妹小話』執筆ルール

## 0. この文書の目的

このルールは、既存の『兄妹小話』から読み取れる作風とキャラクター運用を、新しい一話でも再現するためのガイドである。

目標は、単に「変な兄と強い妹が騒ぐ話」を書くことではない。**身近な疑問を、一彌が異常な射程まで考え抜き、一埜たちが生活者の言葉へ引き戻す。その途中で、言葉・物・世界そのものが会話に巻き込まれる**――という固有の読み味を守る。

以下では、守るべき核を「必須」、話に応じて使うものを「推奨」とする。

---

## 1. 作品の核

### 必須

1. **出発点は日常的で、小さいこと**
   - 寝られない。
   - 眼鏡がない。
   - 猫の尻尾は何のためにあるのか。
   - 水を煮詰めたらどうなるのか。
   - 「男女の友情は成立するか」という雑談。

2. **一彌が、そこから過剰な理屈・連想・装置・世界観を立ち上げる**
   - 問題を解くより先に、問題の定義や背後の構造に夢中になる。
   - 哲学、数学、計算機科学、古典語、宗教、怪談などが、日常へ無理なく無理やり接続される。

3. **一埜が読者の足場になる**
   - 素朴な疑問、生活上の危険、他人への迷惑、感情の機微を指摘する。
   - 難しい話を短い日本語へ翻訳する。
   - ただし常識人に固定しすぎず、面白くなると兄と一緒に遊ぶ。

4. **理屈は現実を侵食する**
   - 比喩や言い間違いで終わらず、睡眠機能、純水の精、眼鏡、食べ物、暗闇などが発話主体になってよい。
   - 専門概念が装置・怪異・空間として実体化してよい。
   - 登場人物は異常を比較的すばやく受け入れ、「なぜ存在するのか」より「今どうするか」を話す。

5. **最後は勝敗より、関係性と笑いへ着地する**
   - 真理が完全には判明しなくてもよい。
   - 兄がひどい目に遭う、妹に叱られる、猫が全部持っていく、日常の用事を忘れていた、などで閉じる。
   - 根底には「この人たちはなんだかんだ仲がいい」という安心を残す。

### 作品を一文で定義するなら

> 兄妹の日常会話が、過剰な知性と雑な超常現象によって宇宙規模まで脱線し、最後は妹のツッコミと生活感に回収される小話。

## 2. キャラクター運用

### 水原一彌

### 必須の性質

- 一人称は基本的に「ぼく」。興奮時や引用的な調子では多少ぶれてもよい。
- 二十歳。大学生を自称するが、市内の大学に学籍はない。この謎は安易に解明しない。
- 妹への愛情は非常に大きく、判断を誤らせるほどである。
- 知識欲と連想力は本物だが、生活能力、注意力、社会的な語用論には穴がある。
- 「わからない」状態に耐えられず、すぐ理論・分類・装置を作る。
- 怖がり、痛がり、慌てる。超然とした天才にはしない。
- 誤りを犯すが、悪意で人を傷つける人物にはしない。指摘されれば謝り、必要なら考えを改める。

### 台詞の癖

- 平静時は少し古風・理屈っぽい。「ふむ」「ううむ」「～ではないか」「つまり……」など。
- 興奮すると大声、感嘆符、疑問符、専門用語が増える。
- 連想は一段で止めず、二段、三段と遠くへ飛ばす。
- ラテン語などの古典語は、意味のある場面で短く使う。訳を添えるか、直後の会話で意味が分かるようにする。
- 知識を披露すること自体より、**知識のせいで新しい面倒が起きる**ことを優先する。

### やってはいけないこと

- 何でも正しく解決する万能人にしない。
- 専門用語を作者の講義として一方的にしゃべらせ続けない。
- 妹への愛を、物語が無批判に正しいものとして承認しない。
- 妹の意思・安全・プライバシーを無視した行動には、必ず作中からツッコミや結果を返す。

### 水原一埜

### 必須の性質

- 九歳。赤い眼鏡と黒いベレー帽が象徴。強い近眼。
- 一彌を「お兄ちゃん」と呼ぶ。
- 反応が速く、台詞は一彌より平易で短い。
- 兄の話を理解できないだけの子ではない。要点をつかみ、生活語に翻訳し、ときには核心を突く。
- 怒る、呆れる、照れる、笑う、怖がる、兄を心配する、という感情の幅を持つ。
- 妹パンチは規格外だが、基本は漫画的な制裁・強制終了ボタン。残酷な負傷描写にはしない。
- 怪談、YouTube、ゲームが好きで、霊感もある。超常局面では兄より頼りになることがある。
- 兄が本当に弱っている時は気遣う。叱責と愛情を両立させる。

### 重要な境界線

- 一埜は九歳の子どもである。性的に描写しない。
- 兄のシスコン言動は、一彌の過剰さを示すギャグや欠点として扱う。
- 一埜には拒否、訂正、制裁、話題変更の権利がある。
- 兄妹愛の着地点は、安心、信頼、じゃれ合い、共犯的な笑いであり、相互の恋愛関係にはしない。

### こにゃん

- 九歳のキジトラ雌。猫として自然に振る舞いながら、人間以上の能力と見識を持つ。
- 鳴き声のあとに括弧で意味を補う形式が基本。
  - 例：`「ハァーン（早くしなさい）」`
- プログラムやアカシックレコードを扱えても、猫らしい欲求・気まぐれ・身体性を失わせない。
- 人間の議論を一声、猫パンチ、食事要求などで終わらせる役に向く。
- 長広舌より、短い鳴き声と強い含意が似合う。

### 中畑為明

- 一彌の同年代の友人。落ち着きと生活能力に欠けるが、善良で真面目。
- RPGや数値計算の文脈では急に頼れる。
- 一彌と同じ側に立って混乱を増やしても、一彌の奇行に巻き込まれる常識寄りの役に回ってもよい。
- 失敗は大きくても、反省と挽回を入れて「無責任な悪人」にはしない。

### 夕畑目ななよ

- 一埜の親友。よく笑い、ノリがよく、社会性が高い。
- 怪しい革命思想、下僕、妙な比喩など、不穏な種を陽気に混ぜる。
- 一彌の権威や専門用語に遠慮せず、雑に切り返せる。
- 読者が言いたい強めのツッコミを担当できる。

### 沖中真宵

- 素直クール。運動と実地対応に強い。
- 感情を過剰に飾らず、観察結果を端的に言う。
- 難解な説明を一文で実用的に要約する役に向く。
- 一彌への「鍛えたい」は恋愛的な関心ではなく、肉体改善への率直な評価として扱う。

### 無生物・概念・作者

- 一時的な話者として登場させてよい。
- 発話内容は、その物の役割・状態を一発で可視化するものにする。
- 作者が出る場合、世界を支配する神ではなく、登場人物に叱られる弱いメタキャラクターにする。
- 「一般通過○○」のような歴史的人物は、専門的な訂正をしたあと本当に通過してよい。

## 3. 基本の表記形式

### 1. 話の入口

基本形は次の順序。

```text
YYYY/MM/DD

一話の題名！

話者名
「台詞」
```

- 題名は内容を端的に煽る。感嘆符・疑問符・「～！？」を使ってよい。
- 場所や状況説明は短く、すぐ会話へ入る。

### 2. 台詞

```text
一彌
「つまり、これは○○なのではないか！？」
一埜
「なんでそうなるの！？💦」
```

- 話者名と台詞を別行に置く。
- 小説的な長い地の文より、台本形式を主軸にする。
- 動作や表情は台詞内の丸括弧に入れてよい。
- 同時発話は `二人「「……」」` のように重ねてよい。
- 一時的な役名は状態込みでよい。例：`午前二時の一彌`、`想像上のヒロイン`。

### 3. ト書き

- `＊……＊` で囲み、場面転換、時間経過、効果音、アイキャッチ、急展開に使う。
- 説明しすぎず、漫画の一コマを指定する感覚で書く。
- `＊　＊　＊` は小さな場面転換やオチの区切りに使える。
- ト書き自体をボケにしてよい。

### 4. 記号と絵文字

- `！`、`？`、`……`、`💦` はテンポと感情を可視化するため積極的に使う。
- `✨` は発見、期待、無邪気な感動。`💢` は叱責。`💕` は愛情や過剰な好意。用途を安定させる。
- 絵文字は一文の意味を補強する位置に置き、全行へ機械的に付けない。
- 大声は文字の反復や濁点で表現してよいが、読みづらくなるほど連発しない。

### 5. 地の文

- 原則は短く、勢いのある実況調。
- 長い説明が必要なら、ナレーションも登場人物同様に少し可笑しくする。
- 内心は丸括弧、または `＊一埜の内心＊` のような区切りで示す。

## 4. 一話を動かす標準エンジン

短編では、次のうち5～8段階を使う。全部を毎回入れる必要はない。

1. **日常の種**
   - 家事、食事、身体感覚、猫、学校、旅行、雑談などを置く。

2. **最初のズレ**
   - 一彌が普通ではない解釈をする。
   - あるいは物・機能・怪異が先に異常を起こす。

3. **一埜の確認**
   - 「それ、要するに何？」「どうして？」「危なくない？」と足場を作る。

4. **理屈の増幅**
   - 一彌が専門概念を持ち出し、異常に整合的な説明を始める。

5. **世界の追随**
   - 説明されていたものが本当に現れる、話す、作動する。

6. **第三者による角度変更**
   - こにゃん、友人、無生物、歴史的人物、作者などが、別の論点や事実を持ち込む。

7. **一度だけ真面目になる**
   - 怖さ、寂しさ、友情、言葉の曖昧さ、兄妹の心配などを短く扱う。
   - 感情は茶化し切らず、数往復ぶん呼吸を置く。

8. **過剰な解決**
   - 妹パンチ、装置の暴走、数学的脱出、猫パンチ、食べ物の射出など。

9. **日常的な後始末**
   - 店員への謝罪、火を消す、猫の世話、下山、注文、片付けなど。

10. **追いオチ**
    - 解決役が遅れて来る。
    - 元の問題が別の形で復活する。
    - 背景の物が一言だけぼやく。

### 短い話の型

`日常の種 → 一彌の誤作動 → 一埜のツッコミ → 異常の実体化 → 一撃で終了`

### 長い話の型

`日常の種 → 議論 → 異常化 → 第三者参入 → 真面目な核心 → さらに異常化 → 仮解決 → 後始末 → 追いオチ`

## 5. 会話の作り方

### 一彌と一埜の一往復を、情報の変換にする

悪い例：

```text
一彌「これは位相空間だ！」
一埜「意味わかんない！」
一彌「だから位相空間なんだ！」
```

良い方向：

```text
一彌「距離を測っても位置が決まらない。ここは距離空間ではない！」
一埜「つまり、いつもの物差しが使えない部屋ってこと？」
一彌「そう！ そして壁同士のつながりだけが――」
一埜「説明を増やす前に出口を探して！」
```

各往復で、少なくとも一つは次へ進める。

- 新情報が出る。
- 誤解が判明する。
- 感情が変わる。
- 問題が大きくなる。
- 解決条件が見える。
- 別のボケへ転ぶ。

### ツッコミを一種類にしない

一埜たちの返しは、次を使い分ける。

- **論理訂正**：「それだと堂々巡りだよ！」
- **生活訂正**：「先に火を止めて！」
- **倫理訂正**：「本人に言わずに改造しちゃだめ！」
- **翻訳**：「要するに、この部屋がバグってるってこと？」
- **観察**：「また頭の中が暴走してる顔をしてる」
- **直球評価**：「キモい」
- **便乗**：「面白そう、やってみよう！」
- **物理終了**：「妹パンチ！」

### 台詞の長短でリズムを作る

- 一彌の長い説明のあとには、短く強い返しを置く。
- 叫びが続いたら、沈黙や小さな動作を挟む。
- 同じ語を反復してテンポを作ってよいが、三回程度で変化を付ける。
- 説明、ツッコミ、実演を交互に置き、説明だけの段落を連続させない。

## 6. 専門知識の使い方

### 基本原則

専門知識は、正しさを飾る小道具ではなく、**ボケを発生させ、関係性を照らし、世界を変形する機構**として使う。

### 手順

1. 日常語と専門概念の間に、読者が追える一本の橋を架ける。
2. 一彌に少し大げさな仮説を立てさせる。
3. 一埜か別の人物に、平易な言葉で要約させる。
4. その概念が現実化した場合の、具体的でくだらない結果を見せる。
5. 必要なら専門的な留保・訂正を入れる。

### 精度

- 用語、綴り、数式、引用、古典語は可能な範囲で確認する。
- わざと飛躍する場合も、どこからが一彌の飛躍なのか読者に分かるようにする。
- 誤用をオチにするなら、作中の別人物、注記、結果の破綻などで誤用だと示す。
- 解説は、非専門家が「何が変なのか」をつかめる長さにする。
- 専門家だけが気づく二重の笑いは歓迎。ただし、それが分からないと話全体が読めない構造にはしない。

### 古典語・引用

- 原文だけで読者を置き去りにしない。
- 直後に訳を付ける、返答で意味を示す、誤訳を人物に訂正させる、のいずれかを行う。
- 長文をそのまま引用するより、状況に合う短句を変なタイミングで使う方がこの作風に合う。

## 7. 超常現象とメタ表現

### 超常現象

- 出現理由は説明してもよいが、説明し切る必要はない。
- 登場人物の驚きは短めにし、すぐ会話や対処へ移る。
- 科学、宗教、怪談、数学、プログラムは排他的に扱わず、同じ卓上へ置いてよい。
- 解決法は「理論的にはそれっぽいが、実行絵面がばかばかしい」ものが望ましい。

### パラレル展開

- 一つの前提から複数のオチを試してよい。
- 二つ目以降は、前の展開より抽象的、大規模、またはメタにする。
- 本筋を否定するのではなく、「別の遊び」と明示する。
- 長くしすぎず、各展開に独自のオチを持たせる。

### 作者の登場

- 作者は無謬ではない。
- 書き始めた設定に自分で困り、登場人物から責任を追及される側に置く。
- キャラクターへの偏愛を自覚的なメタギャグにしても、キャラクターの尊厳と安全は守る。

---

## 8. 感情の扱い

笑いの奥に、短い本音を置く。

- 一彌の奇行の奥には、妹を失いたくない怖さ、言葉が分からない不安、人とうまく関われない寂しさなどがありうる。
- 一埜の怒りの奥には、兄を嫌いになれない親しさと、危なっかしい兄を現実へ戻したい気持ちがある。
- 友人同士の議論では、「誰が論理的に勝ったか」より、なぜその言葉を今その人へ言いたいのかを見る。
- 真面目な場面を入れた直後、必ず急いでギャグに戻す必要はない。数行だけ静けさを保つ。
- ただし、作品全体を説教や告白だけで終わらせず、最後には小話らしい軽さを戻す。

## 9. ギャグの設計

### よく合うギャグ

- **字義通り化**：言葉や比喩が本当に動作する。
- **担当機能の人格化**：睡眠、夢、暗闇などが職務怠慢をする。
- **専門語の生活侵入**：忘却関手、デッドロック、遂行的発話などが家の問題になる。
- **権威の雑な召喚**：専門家や歴史的人物が通りすがって訂正する。
- **物体の被害者コメント**：食べ物、眼鏡、スマホ、トイレなどが状況を一言で示す。
- **過剰な物理結果**：妹パンチで兄が遠くへ飛ぶが、すぐ次の台詞へ戻る。
- **遅すぎる正常化**：担当機能や解決役が、全部終わってから仕事を始める。
- **定義のすり替わり**：一般論だったはずが、実は関係確認や感情の話だったと判明する。

### 控えるもの

- 人格や属性そのものを見下すだけの笑い。
- 子どもの性的な描写。
- 現実の痛みを長く描く暴力。
- 読者が専門知識を知らないことを嘲る笑い。
- 同じツッコミと同じ妹パンチだけに頼る展開。
- ネットミームの羅列だけで成立させる話。

---

## 10. 連続性と自由度

### 固定するもの

- 年齢、呼称、主要な性格、象徴的な持ち物。
- 一彌と一埜の基本的な信頼関係。
- こにゃんの猫らしさと超常的能力の両立。
- 妹パンチの漫画的な威力。
- 一彌の学籍の謎は、明確な設定変更がない限り謎のまま。

### 柔軟でよいもの

- 超常現象の原理。
- 一話限りの装置や人格化された機能。
- 物理法則。
- 語り手と作者の位置。
- 複数のパラレルな結末。

### 原則

設定の整合性より、**キャラクターの反応の整合性**を優先する。世界が突然おかしくなっても、一彌ならどう理屈を付け、一埜なら何を心配し、こにゃんなら何を要求するかがぶれなければ、この作品らしさは保たれる。

## 11. 推敲チェックリスト

### キャラクター

- [ ] 一彌は頭がよいだけでなく、どこか生活的・社会的にずれているか。
- [ ] 一埜はツッコミだけでなく、自分の好奇心や感情で動いているか。
- [ ] 兄の過剰愛に対し、一埜の意思と境界が守られているか。
- [ ] 脇役には、主役二人とは違う物の見方があるか。
- [ ] こにゃんを出した場合、万能な人間の代用ではなく猫としても振る舞っているか。

### 構成

- [ ] 冒頭の種は一文で説明できるほど身近か。
- [ ] 三～五往復以内に最初のズレが起きるか。
- [ ] 中盤で問題、論点、感情のいずれかが一段深くなるか。
- [ ] 長い説明のあとに、短い返しや具体的な出来事があるか。
- [ ] 解決後に後始末か追いオチがあるか。

### 専門知識

- [ ] 用語は概ね正確か。
- [ ] 非専門家にも、何が面白いのか伝わるか。
- [ ] 知識がギャグか人物理解に働いているか。
- [ ] 一彌の推論上の飛躍を、作品自体の事実と混同させていないか。

### 表現

- [ ] 誰が話しているか迷わないか。
- [ ] 絵文字と記号は感情を補強しているか。
- [ ] ト書きは一枚絵として想像できるか。
- [ ] 叫び、説明、沈黙、短い返しのリズムに変化があるか。
- [ ] 最後の一～三往復に、読み終わりの軽さがあるか。

## 12. 最小プロンプト

新しい一話を書く際は、少なくとも次を決める。

```text
日常の種：
一彌が持ち出す理屈／装置：
一埜が最初に指摘する現実的問題：
理屈が実体化した姿：
途中で見える本音または関係性：
解決方法：
最後の生活的な後始末／追いオチ：
```

迷った場合は、次の一文から始めればよい。

> 一埜がごく普通の疑問を口にしたところ、一彌がそれを存在論上の問題として受け取り、家の中にその理論が実体化してしまう。
